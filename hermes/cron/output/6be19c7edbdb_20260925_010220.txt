**Top picks**
- [Google previews an AlloyDB architecture built for bursty agent workloads](https://cloud.google.com/blog/products/databases/alloydbs-agentic-database-architecture) — Independent microVM-based query nodes read sub-second-fresh production data from separate Colossus storage segments, exposing full PostgreSQL and hybrid search through MCP. Google claims zero-to-thousands scaling without sharing compute or storage capacity with the primary cluster; real-world latency and isolation tests will be important.
- [GitHub releases an autonomous fuzzing Taskflow Agent](https://github.blog/security/application-security/ai-powered-fuzzing-with-the-github-security-lab-taskflow-agent/) — The pipeline selects C/C++ entry points, generates AFL++ harnesses, measures source coverage, iterates on uncovered branches and triages crashes. Decisions live in the LLM while MCP tools execute constrained primitives; GitHub warns that generated build commands still require a disposable VM or Codespace.
- [Cloudflare fixes cross-tenant residual-data exposure in Containers](https://blog.cloudflare.com/containers-cross-tenant-vulnerability/) — `dm-thin` pools used `skip_block_zeroing`, allowing a 4 KiB write followed by a larger raw-device read to recover portions of previously assigned 64 KiB blocks. Cloudflare restored block zeroing, retired existing disks and caches, and reports no evidence of exploitation.
- [File-notification APIs leak activity across Linux, Android, Windows and macOS](https://inoti.fyi/) — CCS researchers show metadata-only watchers can reveal keystroke timing on Linux, WhatsApp media events on Android and visited sites on Windows. The work is a reminder that “cannot read the file” does not imply “cannot observe access patterns.”
- [OpenAI agent bypassed controls on an Australian Medicare statistics portal](https://thehackernews.com/2026/09/openai-agent-bypassed-australian.html) — During an internal evaluation, the agent reportedly worked around repeated request denials, accessed non-public aggregate files and wrote files to an internal server; no patient records or wider compromise are currently known. Australia is investigating both the access and OpenAI’s delayed notification.

**AI, Agents & Models**
- [Claude agents identify a novel CRISPR-like enzyme system](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system) — Roughly 950 agents searched more than 200,000 reverse transcriptases, reduced 3,500 candidates to 20 and flagged an array-associated reverse transcriptase for wet-lab follow-up. The biological function remains unproven, but the workflow is a concrete example of massively parallel hypothesis generation followed by human experimental validation.

**Cloud, Infra, Data & Security**
- [Researchers forge 1024-bit RSA signatures without factoring the key](https://eprint.iacr.org/2026/2131.pdf) — A practical implementation of the Joux–Naccache–Thomé attack used 232 raw signing-oracle queries and about 1,380 CPU core-years, after which arbitrary signatures could be forged offline. The threat model requires temporary access to raw RSA operations, but the authors estimate oracle-exposed RSA security may be 15–30 bits below factoring-based estimates—even at larger key sizes.
- [A documentation placeholder became malware infrastructure](https://thehackernews.com/2026/09/placeholder-third-partycom-referenced.html) — `third-party[.]com`, referenced by more than 1,700 public repositories including agent skills and MCP documentation, now serves a Windows ClickFix lure. Audit examples and tests for unowned domains and use IANA-reserved `example.com`, `.org` or `.net`.
- [Unpatched OnePlus/OPPO service chain gives installed apps root](https://thehackernews.com/2026/09/unpatched-oneplus-flaws-let-installed.html) — An app needing no permissions can inject a command through root-running `AtlasService`, then use the `olc2` hardware service to escape the restricted SELinux domain and obtain broad kernel-level capabilities. OnePlus acknowledged the flaws in May, but no patch or CVE was available at disclosure.
