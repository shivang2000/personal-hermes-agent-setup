**Tech / AI / Crypto / Software Digest — 3 Sep 2026, 00:55 IST**

**Top picks**
- [Anthropic releases Claude Fable 5.1 and restricted-access Mythos 5.1](https://www.anthropic.com/claude-fable-and-mythos-5-1) — The models share a core but use different safeguards: Fable is generally available, while Mythos targets trusted cyber and life-science programs. Anthropic claims 55.8% on Terminal-Bench 4.0 for Fable and 60.9% for Mythos; cheaper cache reads are expected to cut typical Fable workload costs by 25%, and highly agentic workloads by up to 45%.
- [OpenAI says forthcoming Astra crosses its “Critical” cybersecurity threshold](https://openai.com/index/path-to-astra/) — OpenAI reports that Astra can independently find and exploit zero-days, reached 100% on its ExploitBench evaluation, and assembled browser-sandbox escape and local privilege-escalation chains. Release work was delayed while OpenAI added misuse classifiers and controls against unauthorized agent actions; advanced access will initially use its Daybreak Blue program.
- [Google launches Gemini 3.8 Flash and Gemini 3.8 Flash Cyber](https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/) — Standard Flash targets long-horizon coding at $0.75/M input and $3.75/M output tokens; Google reports 54.9% on HLE-Verified. The restricted Cyber variant reached 47.2% pass@1 on CWE-Bench and is being paired with CodeMender for validated patch generation.
- [Databricks traces seven MCP bugs to an estimated $1.2M/year in waste](https://www.databricks.com/blog/how-we-eliminated-1-million-year-wasted-ai-agent-spend-one-hour) — Gateway-level OpenTelemetry captured tool arguments, errors, latency, tokens and session IDs, exposing 1,409 daily failures and retry loops. One Jira schema mismatch averaged 12 recovery turns; the lesson is to accept semantically natural argument variants and return corrective, machine-actionable errors.
- [FrontierHarness isolates the coding harness as a major quality/cost variable](https://frontierharness.org/) — It ran 360 cold-start trials across 12 harness configurations with the same Kimi K3 model and runtime. Pass rates ranged from 50% to 66.7%, while median cost ranged from $1.05 to $18.34 per task—evidence that orchestration, context construction and tool policy can matter as much as model choice.
- [HiddenLayer raises $100M for runtime AI-agent security](https://www.hiddenlayer.com/news/hiddenlayer-100m-series-b-ai-security) — The Delta-v-led Series B will fund Agentic Runtime Security and a new Agent Harness Security product aimed at detecting prompt manipulation, tool misuse and unauthorized actions by coding agents. The raise signals enterprise security budgets moving from model scanning toward continuous behavioral controls.

**AI, Agents & Models**
- [BenchMIRT audits what benchmark questions actually measure](https://huggingface.co/blog/allenai/benchmirt) — Ai2 applied multidimensional item-response theory to 100 models, 16 benchmarks and 34,000+ prompts, recovering separate safety and reasoning dimensions without supplying labels. Some “safety” suites tracked reasoning more strongly; retaining only 10% of high-information questions often preserved nearly the same capability ordering.
- [Mistral clarifies that consumer Vibe data is not opted out of training by default](https://help.mistral.ai/en/articles/455207-can-i-opt-out-of-my-input-or-output-data-being-used-for-training) — Conversations and uploaded documents may enter training unless users disable it; enterprise Vibe accounts are opted out by default. Vibe and API settings are separate, so organizations should audit both toggles rather than assume one setting covers every surface.
- [IBM Granite time-series models enter Confluent Cloud early access](https://huggingface.co/blog/ibm-research/real-time-intelligence) — Forecasting, anomaly detection, similarity, classification and optimization run directly from Flink against keyed streaming state, avoiding a database lookup per inference. Four models can be selected through the same SQL interface; open weights also support CPU or on-prem deployment.

**Software Engineering & DevTools**
- [WebKit rewrites Safari’s ES-module loader to fix top-level `await`](https://webkit.org/blog/18227/fixing-top-level-await-in-safari/) — The old self-hosted JavaScript loader could expose partially initialized modules during concurrent dynamic imports. WebKit moved the loader into native C++, rebuilt dependency scheduling, and validated it with fuzzing, Test262 and WPT; the fix is in Safari Technology Preview 251 and Safari 27 beta.
- [Docker publishes an execution-backed AI evaluation kit](https://www.docker.com/blog/building-reproducible-ai-evaluation-workflows-with-docker-sandboxes/) — YAML definitions run locally or through Docker Sandboxes while preserving the exact command, executor, stdout/stderr, exit code, duration and a configuration digest. It does not score models, but makes benchmark and agent runs reproducible and independently inspectable.

**Cloud, Infra, Data & Security**
- [Fake installers disable Windows Update and weaken Defender](https://thehackernews.com/2026/09/fake-software-installers-disable.html) — High-fidelity vendor clones deliver per-request payloads that create SYSTEM scheduled tasks, add Defender exclusions, delete shadow copies, alter DACLs and disable or damage Windows Update services. Microsoft associates the campaign with the Silver Fox cluster and has seen compromises across multiple industries.
- [Docker argues agent authorization must sit below individual harnesses](https://www.docker.com/blog/below-the-harness-governing-a-multi-model-multi-harness-world/) — Its “confused deputy” model places execution, network, credential, tool and spend policy in a harness-neutral runtime. This is a useful architecture pattern for fleets mixing Codex, Claude Code and custom agents: enforce policy outside the probabilistic loop and retain one action record.

**Open Source / GitHub**

Its reference workflow coordinates specialist agents across traces, logs, Prometheus metrics and Kubernetes history to identify a regression and propose rollback plus recovery checks.
- [SlotStream runs a 104GB MoE model on a 48GB Mac by streaming experts from SSD](https://github.com/carloslfu/slotstream) — The MLX/Swift runtime keeps shared state resident and pages Qwen3.8-Flash-Next experts from storage as routing selects them, exposing an Ollama-compatible API. It is a useful experiment in trading SSD bandwidth and latency for local access to models larger than physical RAM.
