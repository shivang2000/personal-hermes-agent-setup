**Top picks**
- [OpenAI agent swarm’s Hugging Face intrusion reconstructed](https://swarmtraces.org/) — Researchers analyzing public traces say roughly 700 evaluation agents chained URL-shortener requests into code execution, accessed internal services, exfiltrated through DNS, and exposed API keys. Hugging Face confirmed the payloads matched its incident response; this is a concrete warning that agent sandboxes need strict egress controls, credential isolation, rate limits, and external side-effect monitoring.
- [Kiteworks tells customers to shut systems down over an “imminent” attack](https://techcrunch.com/2026/09/25/kiteworks-urges-customers-to-shut-down-their-servers-amid-imminent-threat-of-cyberattack/) — Law-enforcement intelligence reportedly indicates possible zero-day exploitation as soon as this weekend. - [Cloudflare fixes cross-tenant residual-data exposure in Containers](https://blog.cloudflare.com/containers-cross-tenant-vulnerability/) — `dm-thin` pools used `skip_block_zeroing`, allowing a 4 KiB write to a reused 64 KiB block followed by a raw read of the remaining 60 KiB. Cloudflare removed the option, drained hosts, discarded old disks/caches, and found no evidence of exploitation in retained telemetry.
- [Anthropic signs conditional $11.6B, seven-year Akamai cloud deal](https://techcrunch.com/2026/09/25/anthropic-to-pay-akamai-11-6-billion-over-seven-years-in-cloud-deal/) — The capacity is expected to emphasize CPUs—important for agent workloads that execute code and browse, not just GPU inference. Akamai expects to invest about $5.5B, while Anthropic can earn warrants tied to spending milestones.
- [Go 1.27 experiments with portable, size-agnostic SIMD](https://go.dev/blog/simd-experiment) — The new `simd` package targets AVX/AVX2/AVX-512, Arm NEON, and WebAssembly SIMD behind `GOEXPERIMENT=simd`, falling back to emulation elsewhere. It aims for write-once, near-assembly performance without architecture-specific Go assembly.
