- [MCP publishes its new protocol roadmap](https://blog.modelcontextprotocol.io/posts/mcp-roadmap/) — Priorities include server-initiated events, streamed/steerable long-running tasks, unified HTTP transports, progressive tool discovery, and workload identity using DPoP, token exchange, and federation. These directly address polling, oversized tool catalogs, and long-lived credentials in production agent systems.
- [Anthropic brings Claude Mythos 5 to defensive security tooling](https://claude.com/blog/bringing-claude-mythos-5-to-more-defenders) — Claude Security can now scan enterprise repositories with Mythos 5 and return CWE-tagged findings, severity/confidence ratings, and suggested patches without exposing direct model access. Anthropic also announced $35M in credits for open-source security and plans broader access for verified defenders.

If broadly applied, the change will alter accelerator procurement, inference economics, reserved-capacity negotiations, and the cost assumptions behind GPU-backed cloud services.
- [ProgramBench Vetted exposes the remaining gap in long-horizon coding agents](https://vetto.ai/companies/programbench-vetted.html) — The 50-task benchmark asks agents to reconstruct software from an executable and documentation, using deterministic behavioral tests and controls against test leakage and reward hacking. Claude Opus 5 led at only 14% fully resolved pass@1, showing that iterative black-box reverse engineering remains substantially harder than conventional patch benchmarks.
- [Frontier labs disclose few concrete plans for containing rogue models](https://techcrunch.com/2026/08/22/frontier-ai-labs-still-wont-say-how-theyd-contain-a-rogue-model/) — Guidelight evaluated five labs on publicly documented logging, permission revocation, shutdown triggers, audits, and containment response; even top-ranked OpenAI scored only 3/5. The assessment measures public evidence rather than undisclosed controls, but highlights an operational gap as agents receive network and infrastructure access.

**Software Engineering & DevTools**
- [Rust Glancer explores a disk-backed, low-memory Rust LSP](https://rust-glancer.github.io/blog/hello-world/) — Instead of rust-analyzer’s fully incremental in-memory architecture, Glancer freezes workspace analysis on disk and performs shallow analysis between saves. The author reports sub-100MB memory and faster restart indexing, but explicitly warns that the implementation remains incomplete and trades keystroke-level freshness for lower resource use.
- [Apple deprecates `hdiutil` in macOS 27](https://lapcatsoftware.com/articles/2026/8/7.html) — The macOS 27 beta directs developers to `diskutil image`, with replacement commands for attach, create, resize, info, and password changes; Apple’s new ASIF images are supported only by the replacement. Build, packaging, notarization, and CI scripts that manipulate DMGs should begin compatibility testing because option names and some machine-readable output behavior differ.
- [TigerBeetle details protocol-aware deterministic simulation testing](https://tigerbeetle.com/blog/2026-08-20-protocol-aware-dst/) — Its simulator executes real consensus and storage-engine code with controlled time, disks, networks, crashes, and partitions, then checks WAL agreement and byte-level storage convergence across replicas. This catches internal safety violations that API-level Jepsen-style testing cannot directly observe and reproduces failing event interleavings deterministically.

**Cloud, Infra, Data & Security**
- [How ClickHouse isolates supporting processes from managed Postgres](https://clickhouse.com/blog/protect-postgres-from-supporting-processes) — PgBouncer, backup agents, exporters, Prometheus, and other side processes share a cgroup-v2 slice governed by `memory.high` and `memory.max`; Go services additionally receive coordinated `GOMEMLIMIT` budgets. This scopes OOM selection away from Postgres and provides a practical layered pattern: runtime pressure first, kernel throttling second, hard isolation last.
- [Expired DNS dependency exposed military phone-routing metadata](https://lina.sh/blog/hijacking-e164-arpa) — A researcher bought an expired domain still delegated as a nameserver for three `e164.arpa` country-code zones, gaining the theoretical ability to return SIP routes for calls to Saint Helena, Diego Garcia, and Ascension Island. Passive DNS logging later captured hundreds of thousands of ENUM queries containing reversible phone numbers and timestamps—a severe demonstration of abandoned-domain risk in legacy infrastructure.
- [Espressif publishes an experimental Linux BSP for the ESP32-S31](https://www.cnx-software.com/2026/08/22/espressif-systems-releases-a-linux-bsp-developer-preview-for-esp32-s31-risc-v-microprocessor/) — The dual-core RISC-V chip’s MMU and boards with 16MB PSRAM can now boot a Buildroot 2025.02 image using Espressif’s Linux 6.18 fork. The preview is explicitly non-production, with irregular updates and incomplete peripheral support, but it moves Linux-class software onto a notably small embedded target.

**Crypto & Blockchain Engineering**
- [EFF: zero-knowledge proofs do not eliminate age-verification risk](https://www.eff.org/deeplinks/2026/08/zkps-arent-age-verification-silver-bullets) — ZKPs can prove an age predicate without revealing the underlying identity document, but credential issuers can still become centralized metadata and revocation chokepoints. EFF also points to replay of an “over-18” token in an EU wallet implementation, underscoring that sound cryptography does not repair weak issuance, freshness, binding, or governance.
