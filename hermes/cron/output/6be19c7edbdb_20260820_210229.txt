# Tech / AI / Crypto / Software Digest — August 20, 2026, 20:55 IST

**Top picks**

- [Malicious Rust crate `arrayref` 0.3.10 runs a build-time payload](https://safedep.io/arrayref-proc-macro1-rust-build-time-malware/) (SafeDep) — A compromised maintainer account published `arrayref 0.3.10`, which pulled in a typosquatted `proc-macro1` (impersonating dtolnay). The build script of `proc-macro1` fetches an arch-specific binary over TLS (no cert validation) and runs it detached. Crates.io pulled the malicious versions, but `arrayref` sits deep in transitive graphs (egui, winit, iced, tiny-skia) with ~245M lifetime downloads.

- [Mojo is now fully open source under Apache 2.0 with LLVM exceptions](https://modular.com/blog/mojo-open-source) (Modular) — The Mojo compiler, standard library, MAX kernels, and Bazel-based build are all in `modular/modular` on GitHub. Compiler/tooling contributions are not yet open (planned by year-end) but the standard library has accepted contributions since 2024. Significant for anyone building GPU/AI accelerator code in a Python-adjacent syntax.

- [Bun v1.4 released](https://github.com/oven-sh/bun/releases) + [Bun is joining Anthropic](https://bun.com/blog/bun-joins-anthropic) — Bun 1.4.0 dropped today (Jarred Sumner). Bun is now an Anthropic-owned project powering Claude Code and the Claude Agent SDK; it stays MIT-licensed, same team, built in public. The acquisition was announced Dec 2025 but v1.4 is the first major release since.

- [OpenAI "will be a public company in 2027" — CFO Friar](https://www.cnbc.com/2026/08/19/open-ai-ipo-timing-2027-friar.html) (CNBC) — Sarah Friar told staff OpenAI confidential-filed in June, expects a 2027 IPO "or sooner." Q2 revenue $6.7B (+18% QoQ), run rate >$40B; AI coding "work product" at 20M WAU. Anthropic is also confidential-filed; Anthropic run rate reportedly hit $65B at end of July vs OpenAI's $852B valuation.

- [DiffusionGemma Technical Report (arXiv 2608.00146)](https://arxiv.org/abs/2608.00146) (Google) — Discrete-diffusion fine-tune of Gemma 4 MoE (3.8B/25.2B), two-stage SFT + RL/sampler distillation. ~1,500 tok/s on a single H100, ~20 tok/forward pass — substantially faster than AR + speculative decoding. Retains thinking, multimodal, long-context, and can still fall back to AR. Trained on <10% of the starting model's token budget.

- [Sandisk tapes out first HBF memory die, 2027 inference samples](https://www.storagereview.com/news/sandiREDACTED_SECRET) (StorageReview) — High Bandwidth Flash: stacked NAND in an HBM-style package, 512GB/stack, 1.6 TB/s read, "8–16× HBM capacity at similar cost/power." Vendor claim: 8× capex efficiency and 2× GPU efficiency vs HBM for inference; HBF/OCP spec is already out with Google + Tenstorrent contributors.
