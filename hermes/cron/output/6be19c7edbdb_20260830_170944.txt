**Tech / AI / Crypto / Software Digest — 30 Aug 2026, 16:55 IST**

**Top picks**
- [Tencent open-sources Hy4 preview](https://www.tencent.com/tencent-releases-and-open-sources-tencent-hy4-preview/) — The mixture-of-experts model has 770B total parameters, roughly 49B active per token, and a 1M-token context window, targeting coding, research and long-horizon agent tasks. The scale makes independent evals and efficient quantized serving the next questions.
- [SpaceX’s Cursor acquisition costs users direct OpenAI-model access](https://indianexpress.com/article/technology/artificial-intelligence/spacex-cursor-acquisition-openai-models-access-10854362/) — OpenAI plans to end Cursor access on **12 November**, citing uncertainty over contractual compliance after SpaceX bought Anysphere for $60B. Cursor says OpenAI models represent about 5% of traffic and negotiations continue; this is a concrete warning against building coding products around a single provider’s reseller agreement.
- [Qubes OS discloses a dom0 command-injection path](https://www.qubes-os.org/news/2026/08/29/qsb-118/) — A malicious qube receiving a file from dom0 could place shell metacharacters in an error-return filename; dom0 interpolated it into a command passed to `system()`. All releases are affected, with `qubes-core-dom0-linux` 4.3.22 carrying the Qubes 4.3 fix.
- [Samsung demonstrates compute inside LPDDR5X](https://chipsandcheese.com/p/hot-chips-2026-samsungs-processing) — LPDDR5X-PIM adds MAC units to each of 16 DRAM banks, exposing 614 GB/s of internal bandwidth versus 76.8 GB/s over the normal interface and up to 2.4 TOPS per package. Standard DDR commands remain usable, but cache coherence, preemption and concurrent normal/PIM accesses create substantial OS/runtime problems.
- [California passes an open-source carve-out from OS age verification](https://www.tomshardware.com/software/linux/california-lawmakers-unanimously-pass-linux-exemption-from-age-verification-law-software-distributed-under-the-gpl-mit-bsd-and-apache-licenses-are-exempt) — AB 1856 exempts operating systems distributed under modifiable/redistributable licenses, covering GPL, MIT, BSD and Apache projects plus package-manager dependencies. It passed the Senate 39–0 and Assembly concurrence and now awaits Governor Newsom.

**AI, Agents & Models**

The useful production lesson is to combine deterministic tooling, AI review and human domain expertise rather than treating a green compile/test pipeline as semantic validation.

GitHub showed roughly **1.6k stars today and 38.4k total**, indicating unusually rapid adoption for domain-specific agent tooling.
