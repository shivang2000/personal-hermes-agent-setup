**Tech / AI / Crypto / Software Digest — 13 Aug 2026, 00:55 IST**

**Top picks**
- **Grok 4.6 lands as a frontier agentic model** — SpaceXAI released [Grok 4.6](https://x.ai/news/grok-4-6) (Aug 12). Per the [Artificial Analysis page](https://artificialanalysis.ai/models/grok-4-6) it scores 61 on the AA Intelligence Index (tied with GPT-5.6 Sol, behind Claude Opus 5/Fable 5/Kimi K3 max), 500K context, image+text in / text out, 85.8 tok/s. API pricing: $2/$6 per 1M tokens, fast variant 2x. The release post emphasizes long-running agents and self-verification in long trajectories; available immediately in Cursor, Grok Build, OpenRouter, Vercel, Cloudflare.
- **Tailscale helps find a 16-year-old SQLite WAL bug** — [Tailscale engineering write-up](https://tailscale.com/blog/sqlite-wal-reset-bug) traces rare control-plane database corruption to a data race in SQLite between a checkpoint and a write transaction. They shipped a shim to surface the failure, and SQLite added the check in **3.52.0**; Tailscale also added a "SQLitePartyMode" self-healing guard. Useful lesson for anyone using SQLite under aggressive manual checkpointing.
- **Qwen3.8-2.4T-A95B: first Qwen-Max-class open weights release** — Alibaba's [Hugging Face repo](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B) (created Aug 8, last modified Aug 12) is a 2.4T-total / 95B-activated MoE (512 experts, 10 routed + 1 shared), 92 layers, 23×[(3×Gated DeltaNet → MoE) → 1×(Gated Attention → MoE)] hybrid attention, 262K context (extensible to ~1M), `qwen3_5_moe_text` arch with MTP, post-trained (pre+post training stages). Model card claims Coding Agent 86.6 Terminal-Bench 2.1, 80.7 QwenSWEBench, etc. on internal Qwen evals; license tag is the new `qwen3.8-max`.
- **NVIDIA ships Nemotron 3.5 Lightning + NeMo Switchyard** — [NVIDIA blog](https://blogs.nvidia.com/blog/nemotron-lightning-switchyard-rtx-dgx/) (Aug 11). 30B MoE open model aimed at high-volume subtasks inside multi-agent systems (claims up to 4× output speed, 30% faster agentic task completion). Switchyard is an open-source model routing library — internal benchmarks claim ~⅓ the cost of Opus 4.8 at frontier accuracy; LangChain routed 7% of calls to a frontier model on Deep Agents and got 74% cost reduction at 6% accuracy tradeoff. Also trending on GitHub today: [NVIDIA-NeMo/Switchyard](https://github.com/NVIDIA-NeMo/Switchyard).
- **Zed launches Delta + DeltaDB (multiplayer agent IDE)** — [Introducing Delta](https://zed.dev/blog/introducing-delta) (Nathan Sobo, Aug 12). DeltaDB is a new replication layer that keeps conversation and worktree in sync between-commits (not via commits), so threads, comments and agent runs are first-class reviewable artifacts. Threads can move to cloud runners, run in browser via the same Rust app compiled to WebAssembly+WebGL, and connect to third-party agent harnesses (starting with Claude Code).
