**Top picks**
- [OpenAI launches GPT-6 Astra](https://openai.com/index/gpt-6-astra/) — A new flagship aimed at long-horizon software engineering, research, browser/computer use, and document creation. [OpenRouter lists](https://openrouter.ai/openai/gpt-6-astra) a 1M-token context window and standard API pricing of $10/$50 per million input/output tokens; independent evaluation places it near the frontier but behind Claude Fable 5.1 overall.
- [Claude produces the first complete computer-checked proof of Fermat’s Last Theorem](https://www.anthropic.com/research/formalizing-fermats-last-theorem) — Anthropic says dozens of agents, coordinated through Prove2Me and a Claude Code harness, generated 13M lines of Lean and 30,300 proved theorems in 11 days. Lean checked the result using only its three standard axioms, making this a major demonstration of agents plus deterministic verification.
- [Actively exploited Chromium V8 type-confusion vulnerability](https://nvd.nist.gov/vuln/detail/CVE-2026-85046) — CVE-2026-85046 enables arbitrary code execution inside Chrome’s sandbox through crafted HTML and is now in CISA’s Known Exploited Vulnerabilities catalog. Chrome versions before **152.0.7977.82** are affected; downstream Chromium browsers and managed fleets should be updated immediately.
- [Spotify cut Claude Code token consumption by 90% through enforced model routing](https://engineering.atspotify.com/2026/9/portal-by-spotify-cut-my-claude-code-token-usage-by-90) — Hooks block expensive full-file reads above a size threshold and redirect them to cheap Gemini Flash “bulk-reader” and “code-writer” workers through Portal. The practical lesson is to enforce routing at the tool boundary rather than relying on advisory instructions in `CLAUDE.md`.
- [Rust-native React Compiler lands in Vite](https://blog.master.dev/react-now-rusted-all-the-way-out/) — `@vitejs/plugin-react` 6.1 adds experimental native compilation via `react({ compiler: true })`. A 1,036-file React Router application measured the compiler phase dropping from 14.3s to 0.81s and its overall build from 22.1s to 9.3s, though unsupported JavaScript patterns can still trigger compilation bailouts.
- [Cloud in a Bottle launches an open-source personal-cloud platform](https://cloudinabottle.org/blog/launch-post) — It runs applications in hardened rootless containers while providing unified authentication, HTTPS routing, cross-app permissions, and a curated catalog. The AGPL project targets the gap between low-level container platforms and consumer-friendly self-hosting.

**AI, Agents & Models**
- [Artificial Analysis updates its Intelligence Index to v4.2](https://artificialanalysis.ai/articles/artificial-analysis-intelligence-index-v4-2) — The index adds AA-Briefcase for multi-task agentic knowledge work and GDP.pdf for reasoning across 4,592 PDF pages; 40% of its weighting is now private held-out data. Claude Fable 5.1 leads overall, while Astra leads GDP.pdf with a 33.2% all-pass rate.
- [EEBench tests whether agents can design usable electronics](https://eebench.org/blog/can-ai-design-circuit-boards-yet/) — Instead of forcing agents through a CAD GUI, EEBench represents circuits in declarative atopile code so models can edit components, build, simulate, and inspect failures. This isolates electrical reasoning and trade-off quality from generic computer-use ability.
- [AI incident automation risks creating “comprehension debt”](https://www.sylvainkalache.com/blog/ai-handles-incidents-engineers-lose-touch-with-their-systems) — Routine auto-remediation can reduce average MTTR while depriving responders of the practice needed for novel SEV0 failures. The proposed countermeasure is recurrent incident simulation, chaos exercises, and requiring agents to preserve evidence and diagnostic reasoning—not merely output a fix.
