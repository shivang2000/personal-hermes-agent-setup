- [Actively exploited PaperCut NG/MF chain gets Emergency Patch Release 3](https://www.papercut.com/kb/Main/security-bulletin-27-aug-2026-urgent-security-advisory/) — CVE-2026-81578 permits unauthenticated configuration changes and can chain with CVE-2026-82078 for Java bytecode execution. PaperCut reports confirmed incidents and says internet-facing servers should install Release 3—even if an earlier emergency patch was applied—or immediately restrict web access to trusted IPs.
- [Apple sets an end date for general Rosetta support](https://developer.apple.com/news/?id=w5ngl9k2) — macOS 27 will be the final release that runs Intel-only applications on Apple silicon; macOS 26.4 may begin warning users. Developers shipping Intel-only binaries should add arm64 slices now, though Apple plans limited continuing support for older games using Intel frameworks.
- [Hugging Face publishes 207 versioned WebGPU kernels](https://huggingface.co/blog/webgpu-kernels) — `@huggingface/kernels` loads Apache-2.0 WGSL operations from the Hub with contracts, correctness cases and benchmarks attached. Hugging Face reports a 2.57× geometric-mean speedup over ORT WebGPU on matching Apple M4 test cases and launched Fleet to crowdsource cross-device correctness/performance evidence.

**Software Engineering & DevTools**
- [A production `io_uring` investigation shows why concurrency matters more than the API](https://frn.sh/io-uring/) — In Turso’s `O_DIRECT` backend, issuing one SQE at a time prevented block-layer merging; a 32-page application readahead window reduced roughly 196,000 device requests to about 16,300. The measurements also show SQ polling consuming 65% of cycles and direct I/O suffering more cache misses than buffered `pread`.
- [Firefox for iOS adds an optional built-in ad blocker](https://blog.mozilla.org/en/firefox/ad-blocker-on-ios/) — Mozilla uses Apple’s WebKit Content Blocker API with EasyList, avoiding the extension limitations on iOS. It blocks many third-party ads and trackers before loading but intentionally leaves same-site and search ads untouched.
- [AnkiDroid removes its donation link to remain on Google Play](https://github.com/ankidroid/Anki-Android/issues/21656) — Google rejected updates because the app linked to its 501(c)(6) fiscal host, despite Play policy exempting some tax-exempt donations. The volunteer project shipped 2.24.1 without the link rather than risk removal on September 11, illustrating how store billing enforcement can directly constrain OSS funding.
- [Jujutsu creator Martin von Zweigbergk joins East River Source Control as CTO](https://ersc.io/blog/martin-joins-ersc) — The move puts the creator of the increasingly popular Git-compatible VCS inside a company focused on source-control infrastructure.
