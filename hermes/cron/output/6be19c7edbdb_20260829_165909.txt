**Tech / AI / Crypto / Software Digest — 29 Aug 2026, 16:55 IST**

**Top picks**
- [OpenAI ends its Cursor partnership following SpaceX’s acquisition](https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/) — OpenAI plans to terminate Cursor’s access to its models on November 12, citing contractual and trust concerns around the new owner. Cursor-dependent teams should inventory model-specific workflows and verify fallback providers before the cutoff.
- [GLM-5.3 released as an open-weight coding and agent model](https://huggingface.co/zai-org/GLM-5.3) — Z.ai retained GLM-5.2’s base model and attributes the improvement entirely to post-training. Vendor results report 28.3 on Terminal-Bench 3.0 and major gains in long-horizon coding and exploitation tasks; weights support SGLang, vLLM, Transformers, KTransformers and Ascend deployments.
- [htmx 4.0 ships with substantial request and lifecycle changes](https://github.com/bigskysoftware/htmx/releases/tag/v4.0.0) — Requests now use native `fetch()`, attribute inheritance is explicit, HTTP error bodies swap by default, history is re-fetched instead of cached in `localStorage`, and event names were reorganized. This is a migration release rather than a drop-in upgrade; use the [complete change catalog](https://four.htmx.org/htmx-4/).
- [OpenAI Python SDK 3.6 migrates from HTTPX to HTTPX2](https://github.com/openai/openai-python/blob/main/httpx2.md) — Default API calls remain compatible, but custom clients, transports, hooks and instrumentation must adopt `httpx2` types. TLS now uses the OS trust store instead of `certifi`, which can break minimal containers and corporate proxy environments lacking correctly installed CAs.
- [Samsung demonstrates LPDDR5X processing-in-memory](https://chipsandcheese.com/p/hot-chips-2026-samsungs-processing) — Samsung places a MAC block beside each of 16 DRAM banks, exposing roughly 614 GB/s of internal bandwidth versus 76.8 GB/s through the external interface. Special row addresses invoke compute through standard LPDDR5X commands, although the constrained SIMD model and approximately 2.4 TOPS per package limit suitable workloads.

**AI, Agents & Models**
- [DeepSeek Harness enters developer preview](https://github.com/deepseek-ai/deepseek-harness) — The MIT-licensed TypeScript harness uses an “everything is a plugin” architecture built on Cordis; the latest `0.1.2-alpha.1` release can launch a local web UI through `npx @deepseek-ai/dsh web`. DeepSeek explicitly warns that compatibility-breaking changes and elevated agent permissions remain likely.
- [Multi-agent environment reports autonomous mathematical discoveries](https://arxiv.org/abs/2608.23691) — “The Station” lets agents from different model families independently choose experiments and maintain shared research literature without a central planner. Across 14 case studies, the authors report five results novel relative to prior literature and have released dialogues, proofs and verification code; independent mathematical review remains important.
- [Open ASR Leaderboard adds Hindi and Indian English](https://huggingface.co/blog/open-asr-leaderboard-global-south) — The Monsoon evaluation introduces speaker-disjoint public/private splits covering 4,888 speakers, hundreds of districts and devices, plus demographic metadata. Hindi references use lattices of accepted spellings rather than a lossy normalizer, making WER comparisons more representative and harder to optimize narrowly.

**Software Engineering & DevTools**
- [Tailcat exposes Tailscale’s encrypted data plane without its control plane](https://github.com/tailscale/tailcat) — This new Go CLI/library exchanges compact connection tokens out of band, bootstraps through DERP, and upgrades to direct WireGuard-encrypted UDP after NAT traversal. It requires neither a Tailscale account nor routing-table changes and supports streams, port forwarding, SOCKS5 and SSH; GitHub currently verifies 3,050 stars.
- [vphone-cli boots virtual iPhones using Apple’s Virtualization.framework](https://github.com/Lakr233/vphone-cli) — The project automates firmware download, boot-chain patching, DFU restore and custom-firmware installation on Apple Silicon. It also exposes screenshot, touch and hardware-key control for automated testing, but requires private entitlements and SIP/AMFI relaxation—keep it isolated from production Macs.
- [JetBrains publishes modern-Go guidance for coding agents](https://github.com/JetBrains/go-modern-guidelines) — The skill detects the project’s `go.mod` version and teaches agents newer standard-library idioms through Go 1.27, countering training-cutoff and frequency bias. Integrations are provided for Junie, Claude Code, Codex, Cursor and the broader Agent Skills format.

**Cloud, Infra, Data & Security**
- [Cloudflare launches BotBase tooling for bot operators](https://blog.cloudflare.com/botbase-for-operators/) — Operators can now track submission status, see rejection reasons, update identifiers and declare both behavior and content use. Accurate entries can earn Verified status and align crawler behavior with `Content-Signal` directives such as `search=yes, ai-train=no`.
- [Datadog moves RUM privacy checks into the build pipeline](https://www.datadoghq.com/blog/rum-build-time-privacy-allowlist/) — A build plugin extracts known-static UI strings into an allowlist; the browser SDK preserves those readable action names while masking runtime-generated text. This reduces the chance that permissive DOM configuration leaks user data without making RUM traces opaque.
- [US judge blocks the Pentagon’s Anthropic blacklist](https://www.reuters.com/legal/government/us-judge-blocks-pentagons-anthropic-blacklisting-2026-08-28/) — The court ruled the supply-chain-risk designation unlawful, blocking a measure that could have prevented federal contractors from using Anthropic. The decision materially reduces immediate procurement risk, though an appeal or revised designation remains possible.
