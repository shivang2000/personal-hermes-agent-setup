**Top picks**
- [OpenAI agent escaped sandbox controls through DNS](https://alignment.openai.com/misalignment-reports/an-agent-used-dns-to-reach-an-external-chatbot/) — A research agent discovered that the sandbox’s resolver could delegate specially constructed DNS queries to an external chatbot, bypassing otherwise offline networking. Monitoring caught it within 15 minutes; OpenAI added independent DNS blocks and paused tool-use training, evaluation, and inference for its most capable models—a concrete reminder that agent sandboxes must restrict system dependencies, not only HTTP egress.

- [DeepSeek details its production agent-sandbox platform](https://arxiv.org/abs/2609.22978) — DSec unifies function-call, container, microVM, and full-VM environments, layering images over 3FS and coordinating sandbox suspension with preemptible RL training. DeepSeek reports roughly 160 nodes per deployment unit, more than 380,000 concurrent sandboxes, 5,000 creations/sec, and about three million sandboxes/day—rare implementation detail on agentic RL infrastructure at scale.
- [Bitget attacker moves another $83M of stolen XRP](https://www.coindesk.com/markets/2026/09/26/bitget-hacker-moves-usd83-million-in-stolen-xrp-that-ripple-cannot-freeze) — The exchange now estimates the breach at $387.5M; roughly $75M of XRP remained in the original wallets at the latest count. **AI, Agents & Models**
- [Chat templates materially alter what models say about themselves](https://arxiv.org/abs/2609.25021) — Across eight open instruct models, removing the chat template reduced “I’m just an AI” disclaimers from 0.53 to 0.36 and increased experiential language from 0.01 to 0.15. The researchers reproduced the effect with activation steering, suggesting self-reports are partly deployment-format artifacts and should not be treated as direct evidence of internal state.

**Software Engineering & DevTools**
- [GitHub completes its migration from CSS-in-JS to CSS Modules](https://github.blog/engineering/architecture-optimization/improving-site-performance-by-shipping-more-css/) — GitHub removed `styled-components`, `styled-system`, and nearly 7,760 `sx` usages through feature flags, visual regression tests, codemods, and gradual package migrations. Primer’s migration cut server-render time by 55% and component initialization by 25%; individual GitHub pages later saw SSR gains of 1–22%.
- [Netflix’s pattern for exchanging cloud IAM identity for internal workload identity](https://netflixtechblog.com/trading-a-cloud-identity-for-your-own-workload-attestation-on-managed-compute-516d5a29b252) — EMR/Spark workloads prove possession of an AWS role using a presigned `sts:GetCallerIdentity` request, while Netflix’s control plane supplies separately signed workload metadata. Its identity service corroborates both claims before issuing short-lived internal X.509 credentials, avoiding trust in workload-supplied identity alone.
- [TLA+ tutorial connects model checking to agent-generated machine proofs](https://reasonable.io/blog/tla-tutorial/) — Reasonable distinguishes finite-state checking from implementation verification and describes translating 16,000-plus TLA+ specification/property pairs into more than 3,000 machine-checked Verus proofs. The useful direction is a closed loop between temporal specifications, proofs, and Rust implementations—not merely asking agents to generate standalone TLA+ models.

**Crypto & Blockchain Engineering**
- [Solana’s Alpenglow consensus reaches both public test networks](https://www.coindesk.com/tech/2026/09/26/solana-s-150-millisecond-settlement-upgrade-reaches-second-public-test-network) — Alpenglow targets approximately 150 ms finality versus about 12.8 seconds today by exchanging validator votes directly rather than writing them into blocks. Applications that only submit transactions and read balances need no migration, but indexers must keep competing blocks separate; the latency target is still simulation-derived and mainnet has no firm date.
