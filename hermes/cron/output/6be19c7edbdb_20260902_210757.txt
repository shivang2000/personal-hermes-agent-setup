**Top picks**
- [Anthropic releases Claude Fable 5.1 and restricted-access Mythos 5.1](https://www.anthropic.com/claude-fable-and-mythos-5-1) — Fable is generally available across Anthropic, AWS, Google Cloud and Azure; Mythos exposes stronger cyber/bio capabilities through trusted-access programs. Cache reads fall 75% to $0.25/M tokens, which Anthropic estimates cuts typical workload cost 25% and highly agentic workloads by up to 45%.
- [Google launches Gemini 3.8 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash) — The agent-focused Flash model accepts text, images, video, audio and PDFs with a 1,048,576-token input limit and 65,536-token output limit. It supports code execution, function calling, structured output, search/Maps grounding and preview computer use.
- [curl 8.22.0 fixes nine newly published vulnerabilities](https://curl.se/docs/security.html) — The advisories cover an OpenSSL provider use-after-free, certificate-pinning and authentication bypasses, HTTP/2 server-push UAF, cookie-boundary errors and unsafe connection reuse; affected releases extend through 8.21.0. [AISLE says its autonomous audit found six](https://aisle.com/blog/aisle-discovered-six-curl-cves-after-openai-and-anthropic-found-zero), all rated Low, after general frontier-model scans returned no findings—a useful demonstration that harness and triage design can matter more than the base model.
- [FBI investigates apparent source of a marketplace offering 153M+ driver-license scans](https://krebsonsecurity.com/2026/09/fbi-probes-service-selling-153m-drivers-licenses/) — Krebs traced sampled records toward Louisiana identity-verification provider IDScan.net using travel/rental timestamps and infrared/UV scan formats; IDScan says it is investigating. The advertised scale remains unconfirmed, but builders should treat raw identity-document retention as breach-critical data rather than ordinary KYC telemetry.
- [NVIDIA details Vera, an Arm CPU optimized for agent execution](https://www.nvidia.com/en-us/data-center/vera-cpu/) — Vera targets the CPU side of agent loops—compilation, Python tools, code analysis, sandboxing and orchestration—with Olympus cores and field-replaceable LPDDR5X/SOCAMM memory. NVIDIA claims up to 1.8× agentic-sandbox performance and 2× memory bandwidth versus its x86 baseline; a 256-CPU rack is designed for 22,500 concurrent environments.

**AI, Agents & Models**
- [OpenAI outlines the path to Astra and “Critical” cyber capability safeguards](https://openai.com/index/path-to-astra/) — Astra is the first OpenAI model described as crossing the company’s Critical cybersecurity threshold. The key engineering question is no longer only model capability, but how exploit-capable systems are access-controlled, monitored and deployed without making advanced offensive capability broadly reusable.
- [Quasar 438B targets low-latency enterprise agents](https://multiversecomputing.com/resources/introducing-quasar-438b-europe-s-leading-ai-model) — Multiverse Computing’s English/Spanish reasoning model is available through its CompactifAI API. The company reports an Artificial Analysis Intelligence Index score of 43, 69.3 on Terminal-Bench v2.1 and 15.3 seconds for a 500-token response; these are vendor-selected comparisons and should be independently tested.
- [Mistral clarifies that consumer Vibe data is eligible for training unless users opt out](https://help.mistral.ai/en/articles/455207-can-i-opt-out-of-my-input-or-output-data-being-used-for-training) — Enterprise Vibe customers remain opted out by default, while consumer users must change the setting themselves. Vibe and API controls are separate, and uploaded documents count as input data—worth auditing before putting proprietary repositories or documents into either product.
- [Two audits expose brittle sourcing in grounded AI search](https://trellner.com/reports/manufactured-sources-behind-ai-recommendations/) — In 7,534 Perplexity citations across software-buying queries, Trellner found 59.8% came from domains outside the top 100,000 and identified three apparently related sites with 215,128 generated “best software” pages. A [separate Haus audit](https://hausresearch.com/reports/perplexity-citation-audit/) found 34.7% of citations attached to numeric claims were inaccessible or contained none of the cited sentence’s figures—evidence that citation presence is not a groundedness metric.
- [Research finds symbolic structure can approximate neural representations](https://arxiv.org/abs/2608.29530) — McCoy et al. replace representation-generating processes with closed-form symbolic approximations across arithmetic, logic, code and language tasks while preserving much of model behavior. Targeted interventions on the recovered structures also modify behavior, suggesting a potentially useful route toward mechanistic interpretability.

**Software Engineering & DevTools**
- [Cupertino exposes Apple apps through locally brokered MCP servers](https://cupertino.mgcrea.io/) — The macOS app gives agents access to Mail, Calendar, Notes, Reminders, Messages and other surfaces through one signed process. Writes are unregistered by default, accounts can be scoped, and tool activity is visible locally—a more defensible permission model than granting every IDE or terminal Full Disk Access.

**Cloud, Infra, Data & Security**
- [Kentik analyzes an RPKI-valid BGP hijack against a hosting-software vendor](https://www.kentik.com/blog/latest-bgp-hijack-targets-hosting-software-vendor/) — The attacker forged the origin ASN in the AS path while exploiting a permissive ROA `maxLength`, so route-origin validation still passed; traffic control then enabled issuance of a valid TLS certificate. Operators should align ROA origin and prefix length tightly with actual announcements rather than treating RPKI-valid as hijack-proof.
- [GrapheneOS confirms Pixel 11 retains Memory Tagging Extension support](https://grapheneos.social/@GrapheneOS/117194007157499435) — The correction matters because hardware MTE lets hardened Android builds detect classes of heap memory corruption with substantially stronger guarantees than software-only mitigations.
