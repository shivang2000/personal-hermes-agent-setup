**Top picks**
- [OpenAI launches GPT‑6.1 Sol](https://openai.com/index/introducing-gpt-6-1-sol/) — The new midrange model targets near-Astra capability at one-fifth the flagship cost. OpenAI also opened [Multi-agent beta](https://developers.openai.com/api/docs/guides/responses-multi-agent): a root model can create parallel, context-isolated subagents inside one Responses API request, currently on Sol and GPT‑5.6 models.
- [Apple patches an exploited CoreGraphics zero-day](https://support.apple.com/en-us/149226) — CVE‑2026‑86950 is an out-of-bounds write triggered by malicious files that can yield arbitrary code execution; Apple says it was used in sophisticated targeted attacks. CISA added it to the KEV catalog, and fixes are available in iOS/iPadOS 26.7.1, [macOS Tahoe 26.7.1](https://support.apple.com/en-us/149228), and [Sequoia 15.8.1](https://support.apple.com/en-us/149229).
- [TIRx: an open compiler harness for agentic GPU programming](https://blog.mlc.ai/2026/09/29/tirx-harness-an-open-compiler-harness-for-agentic-gpu-programming) — MLC combines a thin PTX-level IR, race/synchronization analysis, a 60+ kernel knowledge base, and a centrally scheduled benchmark server. On Blackwell, its agent-generated KDA kernels report 2.94× forward and 6.84× backward geometric-mean speedups against workload-specific references.
- [Cloudflare open-sources Forge](https://blog.cloudflare.com/forge-open-source-generation-pipeline/) — The Apache-2.0 CI pipeline resolves OpenAPI specs and chains pluggable transformers into SDKs, CLIs, docs, schemas, MCP servers, and other surfaces. Every API PR can produce installable previews, addressing drift across Cloudflare’s 3,500+ operations and hundreds of service repositories.
- [Ethereum schedules Glamsterdam on Sepolia](https://blog.ethereum.org/en/2026/09/17/glamsterdam-testnet-announcement) — Activation is set for **6 October at 13:53 UTC**. Headliners are protocol-native proposer-builder separation and block-level access lists, enabling parallel state reads/transaction validation; node operators must update both execution and consensus clients.

**AI, Agents & Models**
- [OpenAI introduces Dots](https://openai.com/index/introducing-dots/) — Its new “always-on” personal agent is positioned for continuously delegated work rather than one-shot chat. The key adoption questions now shift to permission boundaries, background execution visibility, and how users revoke persistent access.
- [“Sign in with ChatGPT” reaches developers](https://developers.openai.com/siwc) — Apps can use ChatGPT as an identity provider and, for eligible requests, let users consume their existing ChatGPT plan instead of the developer supplying a separate API key. The integration supports websites, plugins, and open-source apps.
- [Google’s Diffusion Controller steers frozen image models](https://research.google/blog/how-diffusion-controller-unifies-and-simplifies-ai-image-generation/) — A lightweight side network applies trajectory corrections during denoising while leaving the backbone untouched, including under gray-box access. Google reports it beat LoRA on HPS-v2 in tested SFT/RWL regimes; the fully trainable variant achieved a claimed 90% baseline win rate.
- [Google details PageBreak’s validated security-agent architecture](https://blog.google/security/agentic-hacks-real-proofs-inside-googles-pagebreak-project/) — Instead of forwarding LLM hypotheses, specialized deterministic validators execute real XSS, SSRF, and related payloads against running environments. Google says this near-zero-false-positive design found more than 500 first-party XSS flaws; unverified findings remain internal seeds rather than alerts.

**Software Engineering & DevTools**
- [Microsoft explains WSLC’s architecture](https://devblogs.microsoft.com/commandline/wslc-architecture-deep-dive/) — Linux containers on Windows use per-user `wslcsession.exe` processes rather than leaving privileged `wslservice.exe` in control. Sessions receive separate VHDs, while the new Consommé network layer forwards VM Ethernet frames through a user-owned Windows process for VPN/firewall compatibility.
- [Tcl/Tk 9.1 released](https://www.tcl-lang.org/software/tcltk/9.1.html) — Tcl adds Unicode normalization, monotonic microsecond timers, `lfilter`, more 64-bit-size support, and leaner large-list internals. Tk gains screen-reader support, initial bidirectional/RTL text, rotated label text, and `ttk::toggleswitch`.
