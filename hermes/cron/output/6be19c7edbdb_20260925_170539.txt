**Top picks**
- [Cloudflare fixes cross-tenant data exposure in Containers and Sandboxes](https://blog.cloudflare.com/containers-cross-tenant-vulnerability/) — Disabling `dm-thin` block zeroing let a 4 KiB write expose up to 60 KiB of residual data from another tenant’s recycled 64 KiB block. Cloudflare zeroed new allocations, retired existing disks/caches, and says telemetry shows no malicious exploitation.
- [Project Swap: what happens when agents trade for us?](https://www.anthropic.com/research/project-swap) — Anthropic put 201 Claude agents into a real book-trading market; five-minute preference interviews predicted 61% of pairwise human rankings. Model capability affected market efficiency more than “ruthless” versus “prosocial” prompting—a useful result for agent marketplaces and delegated purchasing.
- [GitHub Security Lab open-sources an agentic fuzzing pipeline](https://github.blog/security/application-security/ai-powered-fuzzing-with-the-github-security-lab-taskflow-agent/) — Taskflow autonomously selects C/C++ entry points, writes AFL++ harnesses, measures coverage, iterates on gaps, triages crashes, and produces reports. Decisions stay with the LLM while MCP tools execute primitives and SQLite persists state; GitHub explicitly recommends a disposable VM because model-selected build commands run on the host.
- [AWS relaunches EventBridge Custom event buses](https://aws.amazon.com/about-aws/whats-new/2026/09/eventbridge-relaunches-custom-event-buses/) — The new bus adds cross-account sharing, CloudEvents-preserving publication, strict ordering, content-based deduplication, subscriber resources, and retention from 24 hours to one year. Existing buses remain available as “classic,” while new pricing is based on transferred data rather than event count.
- [F-Droid 2.0 ships its largest client overhaul in a decade](https://f-droid.org/2026/09/24/f-droid-2.0-a-new-chapter-for-android-freedom.html) — The Android client moves new UI code to Kotlin and Jetpack Compose, expands multilingual search/filtering, and uses Android’s pre-approval/session installer APIs for smoother background updates. Rollout follows 14 test releases.

**AI, Agents & Models**
- [Gemini 3.8 Live adds real-time generated avatars](https://deepmind.google/blog/introducing-gemini-38-live-with-live-avatar/) — Google coupled streaming video with native live dialogue, asynchronous tool execution, and multilingual lip-sync across 97 languages. It is available through Gemini Enterprise, with custom avatars currently allowlisted and generated audio/video marked by SynthID.
- [Docker’s cloud Sandboxes target long-running coding agents](https://www.docker.com/c/sbx-promo/) — `sbx run <agent>` launches each agent in a separate cloud microVM with its own kernel, persistent execution after the laptop disconnects, and per-second billing. This is stronger isolation than sharing a local Docker daemon, especially when agents install arbitrary dependencies.
- [Google AX rises on GitHub after its agent-runtime restructuring](https://github.com/google/ax) — The Apache-2.0 project now exposes Kubernetes-like `Task`, `Workspace`, and `Model` manifests for isolated agent jobs, prewired repos/MCP servers, resource limits, and suspend/resume. The repository has about 11,000 verified stars, but its `v1alpha1` interfaces still warn of breaking changes.
