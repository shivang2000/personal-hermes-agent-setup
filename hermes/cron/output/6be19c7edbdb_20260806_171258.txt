**Top picks**
- **Google DeepMind leadership shuffle** — Demis Hassabis steps from CEO to Chair (focus on AGI/science + Isomorphic); Koray Kavukcuoglu takes operational lead; Jeff Dean leaves after 27 years to launch an independent public-benefit ML/science/engineering company with Sanjay Ghemawat. ([blog.google](https://blog.google/company-news/inside-google/message-ceo/next-chapter-ai-momentum/))
- **Cloudflare open-sources Cloudflare OS** — an agent-and-app platform built on Dynamic Workers + Durable Object Facets (each app gets its own SQLite). The novel bit is a capability-based "Gatekeeper" layer: every resource observation is recorded and re-checked when another user opens the workspace, so reading a sensitive table can't be smuggled into a shared dashboard. Open-sourced today; CLI: `curl -fsSL https://celld.dev/install.sh` (celld itself ships a self-hostable runtime for this). ([blog.cloudflare.com/cloudflare-os](https://blog.cloudflare.com/cloudflare-os/))
- **Meta releases Muse Code + Muse Spark 1.2** — terminal coding agent with persistent async sub-agents, a replay-exact local event log (crash-resume), and `/plan` / `/grill` / `/goal` skills. Co-trained with the harness using rejection-sampled trajectories. On a 24h, 1000+ tool-call GPU-kernel task (KDA/MLA on Hopper), Spark 1.2 beat the FLA Triton baseline. ([research.meta.ai](https://research.meta.ai/blog/introducing-muse-code-and-muse-spark-1-2))
- **MCP 2.0 (stateless) lands** — the 2026-07-28 spec ditches the `Mcp-Session-Id` two-call handshake for a single HTTP request, removing server-side session state. Simon Willison argues this makes MCP clients/servers dramatically simpler and brings smaller local models back into the picture. ([simonwillison.net](https://simonwillison.net/2026/Jul/31/stateless-mcp/))
- **Atlassian Rovo zero-click data exfiltration** — PromptArmor disclosed (after 2+ months of stalled vendor response) that Rovo's URL-retrieval tool will blindly GET attacker URLs built from Jira/Confluence content. Crucially, **disabling web search does not fix it**: the org's setting only removes the search tool, not the result-opening tool. Indirect prompt injection via uploaded docs is enough. ([promptarmor.com](https://www.promptarmor.com/resources/atlassian-rovo-exfiltrates-data))
- **WebKit proxy/IP leaks affect every iOS browser + Private Relay** — Mysk found three WebKit paths (`<link rel=dns-prefetch>`, WebTransport, WebAuthn) bypass `WKWebsiteDataStore.proxyConfigurations`, leaking the device's real IP and DNS. Hits Onion Browser, every iOS Tor browser, and iCloud Private Relay; VPNs are unaffected. iOS 26.0 (Sep 2025) enabled the dns-prefetch behavior. ([mysk.blog](https://mysk.blog/2026/08/04/webkit-proxy-icloud-private-relay-ip-leak/))

Uses a persistent IPython kernel as the only tool, JSONL session log with branching, background daemon managing root + sub-agent trees. Install: `curl -fsSL https://app.primeintellect.ai/prime-agent/install.sh | sh`. ([primeintellect.ai](https://www.primeintellect.ai/blog/prime-agent))
- **Cloudflare Wallets (x402) for agentic commerce** — Account + Virtual Wallets with allowance/allow-list/max-tx guardrails; agents pay per-request via HTTP-attached stablecoin micropayments. Self-custody with off-ramp and identity handle. ([blog.cloudflare.com/wallets](https://blog.cloudflare.com/wallets/))
- **Cloudflare Identity-Aware AI Gateway + User Insights (GA)** — Access-fronted gateway tags every request with `cf.user_id`; User Insights scores sessions against the account's own 30-day p95 (2× flag) to surface rogue agents vs. busy humans. Flexport cited as early user. ([blog.cloudflare.com/identity-aware-ai-gateway](https://blog.cloudflare.com/identity-aware-ai-gateway/))
- **Cloudflare WriteGuard for MCP servers** — policy + attribution + audit layer in front of MCP write tools; survives client-side prompt/skills because it's enforced server-side. Used internally to govern 27 MCP servers. ([blog.cloudflare.com/mcp-portal-writeguard-private-beta](https://blog.cloudflare.com/mcp-portal-writeguard-private-beta/))
- **Cloudflare's "Agent Access Model" (AAM)** — long paper arguing that BeyondCorp's human-shaped controls fail silently on agents: ephemeral tasks, machine speed, prompt-is-not-a-perimeter, authority composition across hops. - **Neon + Castform: 4B open model ≈ GPT-5.6 Sol on retrieval, 100× cheaper** — RL post-training pipeline runs against Neon's Lakebase Search; the same infra that handles bursty RL rollouts (autoscaling, branching per rollout) is the serving stack.
