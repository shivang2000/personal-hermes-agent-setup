**Software Engineering & DevTools**
- [Cloudflare cut 100 TB from the 1.1.1.1 DNS cache](https://blog.cloudflare.com/dns-cache-memory-optimization-1111/) — Across 250B+ entries, five Rust layout changes halved per-entry memory while raising insertion throughput 43% and lowering lookup latency 19%. Techniques included replacing immutable `Vec`/`String` fields with boxed slices/strings, consolidating record lists behind `u16` offsets, bit-packing flags, and removing redundant owner names.
- [GitHub Copilot code review now handles bot PRs and removes large-PR limits](https://github.blog/changelog/2026-08-27-copilot-code-review-resolution-reasons-and-expanded-capabilities) — Full agentic review now works on Copilot cloud-agent PRs and other bot-authored PRs when the organization enables unlicensed-member billing. GitHub also removed the previous 300-file/20,000-line ceiling and added “Addressed,” “Won’t fix,” and “Incorrect” resolution feedback.
- [monty-go embeds sandboxed Python tool orchestration inside Go](https://github.com/fugue-labs/monty-go) — It compiles Pydantic’s Monty interpreter to a 2.9 MB WASM module and runs it through pure-Go `wazero`, without CGO, containers, or subprocesses. Execution pauses at declared external functions, allowing an agent to express loops and multi-tool workflows in one model round-trip while Go retains I/O and resource-limit control.
