**Top picks**
- [Keyv and friends compromised in active Shai-Hulud npm supply chain attack](https://www.aikido.dev/blog/keyv-and-friends-compromised-in-npm-supply-chain-attack) — Attacker compromised the maintainer of the `keyv` family and pushed malicious releases for `keyv`, `flat-cache`, `file-entry-cache`, `cacheable-request`, `cacheable`, `cache-manager`, and several `@cacheable/*` packages, injecting a `preinstall` script (`setup.mjs`) that downloads a Bun runtime and runs a credential-stealing worm. Aikido reports **434 packages / 1,381 versions / ~2B monthly installs** compromised, with community spread to `@picsart/ai-sdk`, `@qlik/embed-runtime`, `picasso.js`, and others. Worth pinning npm versions and auditing `preinstall` hooks immediately.
- [Lilian Weng — "Harness Engineering for Self-Improvement"](https://lilianweng.github.io/posts/2026-07-04-harness/) — Weng's long-form post makes the case that recursive self-improvement in the near term will be driven by the **harness layer** (workflow loops, file-as-memory, sub-agents, eval/perms), not raw model weights. The case study section canonically catalogs the tool surface of modern coding agents (Claude Code / Codex / OpenCode / Cursor) and frames "harness as optimization target" as a peer to prompt/context engineering. Required reading if you're building any agent product.
- [Mistral's Shieldstral: 3B open-weights multimodal moderation model](https://mistral.ai/news/shieldstral/) — Apache 2.0, runs on a single 16 GB GPU, and **frames safety as policy-adaptive question answering** — you pass the policy as natural language at inference time, no retraining. Mistral claims it matches models up to 7× its size on text safety and sets a new SOTA on multimodal moderation, as part of the new "Open Secure AI Alliance" with NVIDIA. The "single binary yes/no logit → calibrated score" design is the interesting part for builders.
- [DeepSeek V4 Flash on a single AMD MI300X — open-source production stack](https://github.com/ryanzhou/deepseek-v4-flash-mi300x) — `ryanzhou` open-sourced the Docker Compose stack, SHA-256-pinned file overlays, ROCm nightly, and AITER tuning tables to serve the 304B DeepSeek-V4-Flash-0731 checkpoint on **one MI300X** (192 GB HBM3) — 168.6 tok/s single-stream decode, 8.9K tok/s prefill, 830 tok/s aggregate across 64 concurrent streams, 256K validated context, no offload. The repo is a practical reference for `fnuz` FP8 on CDNA3, MoE routing, and speculative decoding on AMD that the official vLLM recipe still doesn't cover.
- [Warp Agent CLI](https://www.warp.dev/blog/introducing-the-warp-agent-cli-coding-agent) — Warp extracted its multi-model agent into a standalone CLI that runs in any terminal (Ghostty, iTerm, VSCode, Windows Terminal). Architectural twist: it's built on Warp's pty mux layer, so the agent can drive full-screen programs (sqlite REPLs, vim, mysql), survive `cd`, and even run over SSH with no remote binary. Supports auto-routing across frontier + open-weight models and can delegate to Claude Code / Codex sub-harnesses. Direct shot across Claude Code / Codex CLI.
