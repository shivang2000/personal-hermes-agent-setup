**Top picks**
- [MCP publishes its new protocol roadmap](https://blog.modelcontextprotocol.io/posts/mcp-roadmap/) — Priorities include server-initiated events for long-running agents, unified Streamable HTTP transports, progressive tool discovery, and workload identity using DPoP, federation, ID-JAG, and token exchange. These directly address MCP’s polling, oversized tool catalogs, and long-lived-token problems.
- [Crafted NTFS images can yield root on Linux](https://www.phoronix.com/news/NTFS3-Vulnerability-For-Root) — The mainline NTFS3 driver imports SUID/SGID mode bits from untrusted on-disk extended attributes; an automounted USB can consequently create a setuid-root binary. The issue was reportedly still unpatched at publication—restrict removable media and mount NTFS with `nosuid`.
- [NanoGPT Speedrun compares 153 autonomous optimization runs](https://www.primeintellect.ai/research/nanogpt-speedrun) — PRIME Intellect ran 18 frontier models with published trajectories, token counts, harnesses, and wall times. Fable 5 closed 81.7% of the human-record gap, but consumed 800M tokens over 8.7 days—useful evidence that agent benchmarks need cost and harness normalization, not just final scores.
- [AWS Glue 6.0: Spark 4.1, Iceberg v3 and 30% lower pricing](https://aws.amazon.com/blogs/aws/aws-glue-6-0-now-available-with-30-lower-price-and-full-apache-iceberg-v3-support/) — The serverless ETL runtime moves to Python 3.13 and Scala 2.13, adds Arrow-native Python UDF execution, declarative pipelines, Iceberg variant shredding, geospatial types, and nanosecond timestamps. Existing jobs can select version 6.0 without API changes.
- [Vero benchmarks repository-scale, formally verified agent output](https://vero.verina.io/) — Its 43 Lean 4 projects contain 743 APIs and 2,705 specifications, with submissions rebuilt cleanly and checked against an axiom allowlist. The current best fully solves 27/43 code-and-proof instances, while ten resist every tested configuration—far stricter than partial proof-completion metrics.

**AI, Agents & Models**
- [Why local LLM inference can diverge from reference results](https://forum.level1techs.com/t/why-your-local-llm-feels-dumber-than-it-is/253917) — Controlled Qwen3.6-27B tests show that attention backends, GPU instruction sets, quantization, chat templates, and samplers can alter logits and eventually tool behavior. The practical lesson is to pin the entire serving stack and evaluate long-context, workload-specific traces—not a few temperature-zero prompts.
- [A proposed “Cache-Control” contract for LLM KV caches](https://www.gojiberries.io/cache-control-for-llms/) — The design separates hard constraints—retention, sharing scope, exact versus approximate reuse, and identity—from hints such as expected reuse and miss cost. It maps capabilities already scattered across vLLM, LMCache, SGLang, OpenAI, Anthropic, and Gemini into a portable application-facing policy layer.
- [Munder Difflin: local-first multi-agent office harness](https://munderdiffl.in/) — The open-source harness coordinates 12 CLI-agent providers using isolated Git worktrees, shared memory, schedules, budgets, and circuit breakers; its UI simulation consumes no model tokens. The project reports 3.7K GitHub stars and is a useful orchestration reference beyond single-agent coding loops.
- [Autolith v0.35: a programming agent with a live Common Lisp runtime](https://www.lambda-symbolics.com/autolith) — Autolith keeps tools, memory, conversations, mutation journals, and SBCL execution in one inspectable process; it can modify its own running image and persist replayable private commits. Its recursive-inference environment also processes corpora larger than the model window, though the authors explicitly warn that execution is **not** security-sandboxed.

At this scale, per-query JIT becomes practical for databases and parsers rather than being reserved for only expensive queries.

SDKs, a hosted test PDS, and a sample app are available, but access control provides gating—not encryption—and breaking schema changes are expected.
