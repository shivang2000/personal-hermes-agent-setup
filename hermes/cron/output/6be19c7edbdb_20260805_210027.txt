**Top picks**
- **Cloudflare OS goes open source** — https://blog.cloudflare.com/cloudflare-os/ — Agent + app platform built on Cloudflare Workers/Dynamic Workers + Durable Object Facets. Every "gadget" (doc/sheet/slide/app) is a private V8 isolate with its own SQLite and cap-rpc bridge via [Cap'n Web](https://github.com/cloudflare/capnweb). Security is the headline: an "observation graph" means Gatekeepers re-evaluate the user's access to every resource the agent has *seen* — so a sensitive-table read cannot launder into a public dashboard. Apache‑2.0, 654⭐, runnable locally with `pnpm run-local`. This is the most consequential agent-OS release of the month.
- **Mistral ships Shieldstral‑1.0‑3B for multimodal moderation** — https://mistral.ai/news/shieldstral/ — Apache‑2.0 safety classifier that takes the *policy as a prompt* (binary yes/no over arbitrary text + image); reads a single yes/no logit pair, so a 3B matches up to 21B on text safety and sets SOTA on multimodal moderation. Runs on one 16 GB GPU. Useful as a deployable open guard for product teams that don't want to babysit a vendor model.
- **MCP 2.0 (stateless) shipped** — spec dated 2026‑07‑28 — replaces the two‑request `initialize`+`tools/call` with a single POST carrying `MCP-Protocol-Version`/`Mcp-Method`/`Mcp-Name` headers. No server-side session state, trivially horizontal-scalable, easier to drive from small/local models. Simon Willison has the canonical writeup + three reference implementations: [stateless‑mcp](https://simonwillison.net/2026/Jul/31/stateless-mcp/), [`mcp-explorer`](https://github.com/simonw/mcp-explorer), [`datasette-mcp`](https://github.com/simonw/datasette-mcp).
- **Run 80B Qwen in 4.3 GB RAM on a Mac, 35B on an iPhone** — Show HN, 306 pts — https://github.com/leonickson1 — Aggressive ternary/QRAM-style quantization + mmap'd weights prove you can serve frontier-class local inference on commodity Apple silicon. Companion: [**Maple-Preview**](https://deepgrove.ai) — ternary 20B MoE at 120 tok/s on an iPhone (158 pts), and [Fine‑tune 8B on 4 GB laptop GPU](https://github.com/makazhanalpamys) (131 pts). The "cloud-required for serious models" assumption is now defunct.
- **`LLM 0.32` ships visible reasoning traces + OpenAI Responses + content‑addressable SQLite logs** — Simon Willison, Aug 4 — https://simonwillison.net/2026/Aug/4/llm-32/ — plus updated [`llm-anthropic 0.26`](https://github.com/simonw/llm-anthropic). Useful for any agent-harness team evaluating Claude/Anthropic+OpenAI side by side without instrumenting two divergent tool-calling stacks.
