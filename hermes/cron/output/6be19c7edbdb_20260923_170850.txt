**Top picks**
- [OpenAI launches GPT‑6 Sol and Luna](https://openai.com/index/introducing-gpt-6-sol-and-luna/) — The new midrange and high-volume models halve API prices versus GPT‑5.6 promotional pricing: Sol is $2/$10 and Luna $0.10/$0.50 per million input/output tokens. Both target coding and tool-heavy workflows; OpenAI also added 90%-discounted prompt caching, explicit cache breakpoints, diagnostics, and cache-preserving tool/effort changes.

API pricing falls to $4/$20 per million input/output tokens, with cache reads at $0.20; Sonnet and Haiku 5.5 are due in the coming weeks.
- [Critical WordPress path traversal can become RCE](https://github.com/WordPress/wordpress-develop/security/advisories/GHSA-7hp8-65ch-5whp) — CVSS 9.2, unauthenticated, and applicable when affected theme/server prerequisites exist—including several widely used themes and common Docker/cPanel configurations. WordPress shipped fixes for every maintained/backported branch from 4.7 through 7.1; current users should move to 7.1.2 or their branch’s patched release.
- [Next.js patches critical `ImageResponse` RCE](https://nextjs.org/blog/nextjs-security-update-september-22-2026) — Next.js 16.2.0 through 16.3.5 can execute code under specific conditions when Node.js `next/og` renders improperly escaped Satori SVG output. Upgrade to 16.3.6; Edge `ImageResponse` is unaffected, while 15.5.26 contains related hardening.
- [Amazon CloudWatch Omni brings agent-aware observability to GA](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-cloudwatch-omni-ai/) — Omni maps dependencies and telemetry across AWS accounts, regions, and Azure using OpenTelemetry, then supports natural-language root-cause analysis via AWS DevOps Agent. Its agent view traces prompts, model calls and tools and adds evaluation workflows for LangGraph, CrewAI, OpenAI Agents SDK, Vercel AI SDK and Strands.

**AI, Agents & Models**
- [Better prompt caching for GPT‑6](https://openai.com/index/better-prompt-caching-for-gpt-6/) — Reusable prefixes now qualify within a 30-minute window, while a dashboard and per-request diagnostics identify misses such as changed tools. Developers can prewarm context and vary reasoning effort or callable tools without invalidating the earlier cache.
- [Unreal Agent explores fully asynchronous tool execution](https://unreallabs.ai/blog/unreal-agent/) — Its harness immediately records long-running tools as in progress, continues scheduling work, and invokes the model when results arrive—avoiding polling turns while preserving mid-run user steering. Vendor-published Harbor runs report comparable or better pass rates with 20–40% lower costs than tested Codex/Pi configurations; treat these as early harness-specific results.
- [Jev reproduced as constrained-token classification](https://www.nobodywho.ai/posts/jev-in-25-lines/) — A compact implementation demonstrates the core mechanism: score predefined answer-token logits, normalize them into probabilities, and return a typed decision rather than generated prose. It is a useful reality check on “System One” model claims, though production calibration and decision-specific training remain the differentiators.

**Software Engineering & DevTools**
- [Cloudflare Worker Previews isolate every branch](https://blog.cloudflare.com/worker-previews/) — `npx wrangler preview` now provisions a stable branch URL with separate secrets, configuration, logs, traces, Durable Object namespaces and Container state. That gives coding agents a production-like deploy–browse–inspect–patch loop without sharing staging state or touching production.
- [Cloudflare adds configurable HTTP `Vary` support](https://blog.cloudflare.com/vary-support/) — Cache Rules can normalize negotiation headers, preserve exact values, or bypass high-cardinality variants such as cookies. This addresses the usual `Vary` tradeoff between serving an incorrect representation and fragmenting the cache into nearly unreusable entries.
- [ArchiveBox 0.9 ships a new engine, apps and 50+ plugins](https://docs.sweeting.me/s/archivebox-v0.9-announcement) — The self-hosted archiver adds PostgreSQL, scheduled crawls, authenticated browser personas, resumable orchestration, native clients and a standalone `abx-dl` CLI. It also gains MCP/skill integration and evidence features including Merkle hashes, TLSNotary attestations and OpenTimestamps.

**Cloud, Infra, Data & Security**

- [Drop: rootless Linux sandboxing for coding agents](https://droprun.sh/) — Drop hides the real home directory and isolates processes, mounts, networking, IPC and cgroups inside an unprivileged user namespace, with optional gVisor protection. It preserves access to the host distribution’s installed programs while enforcing file and localhost exposure through TOML policy.
