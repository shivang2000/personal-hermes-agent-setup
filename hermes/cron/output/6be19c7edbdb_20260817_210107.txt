**Top picks**
- **DuckDB v2.0 "Cyanoptera" preview lands, shipping this fall** — Adds first-class client/server via the `quack` extension + `CONNECT` statement (which also pushes SQL down to Postgres/MySQL), full SQL triggers with transition tables, the `VARIANT` shredded-JSON type end-to-end, an `APPROX NEAREST` join for vector search, and a new SQL parser + storage format over 10,000 commits. Quack graduates from preview; expect breaking changes.
- **GitHub is in a major incident** — ~20% error rate on web/API and ~50% on archive/raw downloads, with SAML/OIDC, SCIM, Team Sync, Pages, Webhooks, Actions, PRs, and Copilot all degraded since ~13:40 UTC. Status page is still updating with mitigations; if your CI/SCIM depends on GitHub, expect flaky runs and re-issuances.
- **Wiz Red Agent exploited an AI-generated Copilot "Autofix" PR to reach Snowflake's internal Jira** — Copilot Autofix produced a vulnerable GitHub Actions change in a public repo that granted an exploitable workflow token; Wiz chained it to access Snowflake Jira data fully autonomously, with no human in the loop. Concrete case-study for "AI-generated patches can carry AI-generated vulnerabilities."
- **GPT-5.6 "Sol" is OpenAI's best vision model — and still loses to Gemini 3.5 Flash on cost** — Roboflow's VLM benchmark: object-detection mAP@50 jumped from 13.8 (5.5) → 46.2 (Sol); counting from 64.9% → 73%. Practical tradeoffs: ~10s/image, ~2.5¢/image, XYXY-pixel coords required (wrong format drops 15 mAP), and instability above ~2k×2k pixels. The "best vision model" story is real; the "best for production pipelines" story still points at Gemini 3.5 Flash at 0.8¢/image.
- **Qwen3.8-27B released under Apache 2.0** — 27B dense vision-language model with 256K native (1M extensible) context, hybrid Gated DeltaNet + Gated Attention (16:1 linear:attn layers), MTP, and tunable reasoning via `reasoning_effort` + `preserve_thinking`. Hits 73.0 Terminal-Bench 2.1, 61.7 SWE-bench Pro, 79.5 IFBench — competitive with much larger closed models and runnable on a 24GB GPU. Simon Willison: "excellent, but it defaults to wildly overthinking things" (turn thinking off in single-shot).
- **Germany forces Apple to redesign ATT consent prompts in 4 months** — Bundeskartellamt preliminary finding: the third-party "App Tracking" prompt (with the warning hand icon, dark/ambiguous wording) steers users away from consent while the Apple "Personalised Ads" prompt steers them in. Apple must neutralise the design and let third parties combine/link their consent screens across the EU.
