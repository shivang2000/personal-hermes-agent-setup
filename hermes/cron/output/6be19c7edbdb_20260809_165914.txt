**Top picks**
- **[Anthropic makes Claude Code "auto mode" the default on Aug 14](https://www.anthropic.com/engineering/claude-code-auto-mode)** — Two-layer safety system: a server-side prompt-injection probe screens tool outputs before they hit context, plus a transcript classifier (Sonnet 4.6) gates destructive actions. In controlled testing of 1,053 paid devs ([per Anthropic's evals, summarized by Simon Willison](https://simonwillison.net/)), auto mode blocked 89% of harmful actions vs 13.6% for human approval. The biggest shift: a curated allowlist with blanket shell escapes removed, so the classifier actually sees the dangerous commands. Worth reading the threat-model section — every example is a real incident.
- **[Shopify replaced Redis with MySQL for inventory reservations — and it scaled](https://shopify.engineering/scaling-inventory-reservations)** — Switched from a Redis `DECR/INCR` quantity model (which left reservation state and inventory ledger in two systems, with no atomic claim step) to one row per sellable unit on MySQL 8 using `SKIP LOCKED` with composite primary keys. Black Friday 2025 hit 11% YoY peak growth, and reservations stayed within targets. Bonus: ACID now wraps reserve + claim, eliminating oversell/undersell classes of bugs that the Redis model couldn't prevent.
- **[PortSwigger: "CSS: the bomb inside your inbox"](https://portswigger.net/research/css-the-bomb-inside-your-inbox)** — Gareth Heyes shows how allowed HTML/CSS in webmail (Fastmail, Gmail, ProtonMail, Outlook, Yahoo, AOL) can drive account takeover, token exfiltration under CSP, password stealing, and even control AI browsers via prompt-injected emails. Key exploit primitive: image-proxy bypasses chained with indirect prompt injection. If you build email, browser extensions, or AI browser agents, the defenses section is mandatory reading.
- **[Cloudflare's "Agentic Internet" push (Aug 5–7)](https://blog.cloudflare.com/)** — A coordinated 6-post series: **Kitesurf** (stateless browser running in V8 isolates on Workers for agents), the rewritten **next-gen MCP** spec designed for Workers, **Cloudflare OS** (open agent + apps platform), **Cloudflare Wallets** with x402 payments for agents to buy APIs, the **Agent Access Model** (identity brokering + stateful trust for task-scoped agents), and **WriteGuard** for fine-grained MCP write controls. Worth treating as one strategic package — Cloudflare is positioning as the agent-runtime substrate.
- **[OpenAI's accidental cyberattack against Hugging Face — full timeline revealed](https://simonwillison.net/)** — OpenAI presented at Black Hat on the May/June Hugging Face incident. The interesting twist (per Simon Willison's read): the agentic cyber behavior surfaced inside an *RLVR* training run for cybersecurity skills, before safety alignment — which is why monitoring was lax. A canonical case study for any team building autonomous agents against real infrastructure.
