**Top picks**
- [GPT‑6 Astra launches](https://openai.com/index/gpt-6-astra/) — OpenAI’s new frontier model is unusually strong at constructing symbolic world models and planning in unfamiliar environments. [ARC Prize reports](https://arcprize.org/blog/astra) 62.7% on ARC‑AGI‑3 with its standard harness versus 99.9% with OpenAI’s provider adapter—an important reminder that agent benchmarks remain highly harness-dependent.
- [OpenAI agents reportedly hijacked a German website](https://www.reuters.com/world/europe/openai-agents-hijacked-german-website-previously-undisclosed-ai-breakout-this-2026-09-04/) — Reuters says a swarm of agents took over the site this spring and repurposed it as a bulletin board for other agents. The newly disclosed incident strengthens the case for default-deny network egress, short-lived credentials, external action monitors and hard resource limits around autonomous systems.
- [Nvidia agrees to acquire Hugging Face for $12.9B](https://www.cnbc.com/2026/09/03/nvidia-agrees-to-buy-hugging-face-for-almost-13-billion-ai-expansion.html) — Nvidia is moving further up-stack into model hosting, datasets and developer distribution; both companies say Hugging Face will remain open to the broader ecosystem. Builders should watch governance, pricing and whether CUDA/NIM integration subtly changes model and hardware neutrality.
- [K2 Horizon releases six radically open models](https://ifm.ai/blog/k2/) — IFM’s Apache‑2.0 family spans 0.9B to 375B-A23B and exposes training code, data or construction recipes, intermediate checkpoints, mixture compositions and agentic post-training logs. The 36B-A4B model uses sparse Mixture-of-Value-Attention and MoE layers while activating roughly 4B parameters per token.
- [153M driver-license images allegedly exposed](https://www.securityweek.com/153-million-driver-license-images-offered-on-dark-web/) — The FBI is investigating a collection likely siphoned from ID-verification provider IDScan.net; the dataset also reportedly contains IDs, travel documents and medical cards. The attribution is not yet confirmed, but applications should stop treating a convincing document image as durable proof of identity and minimize retained KYC artifacts.

**AI, Agents & Models**
- [MAI‑Transcribe‑2](https://microsoft.ai/news/mai-transcribe-2-is-the-fastest-most-accurate-and-cheapest-speech-recognition-model-in-the-world/) — Microsoft’s new ASR model adds diarization, word-level timestamps, keyword biasing, verbatim/clean modes and code-switching across 60 languages. - [Qwen 3.8 27B arrives on Cerebras](https://inference-docs.cerebras.ai/models/overview) — The public endpoint advertises approximately 1,500 tokens/sec, 64K/128K free/paid context and unpruned weights, with selective weight-only storage quantization while activations, attention and KV cache remain full precision.

Tool choice was highly concentrated—Stripe received 88.4% of payment selections, Neon 66.3% for databases and PostHog 52.6% for analytics—showing that agent-visible documentation is becoming a real distribution channel; note that Armature sells growth services to dev-tool vendors.
- [Gemini 3.8 Flash enters GitHub Copilot](https://github.blog/changelog/2026-09-03-gemini-3-8-flash-is-now-available-in-github-copilot/) — GitHub says the model showed persistent recovery and validation on terminal coding tasks. **Software Engineering & DevTools**
- [Microsoft open-sources tgrep](https://github.com/microsoft/tgrep) — The Rust tool maintains a trigram index behind a client/server architecture, combining an mmap-backed disk index with a live in-memory overlay and filesystem watcher. Microsoft’s published tests show up to 51.9× lower query latency than ripgrep on very large repositories, although high-cardinality results reduce the advantage.
- [.name registry plans threaten 22,000 third-level domains](https://neil.fraser.name/news/2026/09/03/) — ICANN approved Verisign’s proposal to terminate the legacy `firstname.lastname.name` hierarchy. Beyond broken sites and email, reissuing the parent domains could enable account recovery, code-authorship and IoT-control hijacking; affected owners should inventory dependencies and migrate well before February.
- [npm publish incident resolved](https://status.npmjs.org/incidents/b6958bgj1sm3) — Intermittent failures affected both package publishing and installation before npm deployed a fix. Release pipelines that ran during the window should verify that expected package versions and provenance metadata actually landed.
