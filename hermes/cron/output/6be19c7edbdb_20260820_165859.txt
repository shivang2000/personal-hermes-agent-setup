**Top picks**

- **Stripe to acquire OpenRouter** — Stripe [confirmed an agreement to buy OpenRouter](https://stripe.com/in/newsroom), and OpenRouter [posted its own announcement](https://openrouter.ai/blog/) on Aug 19. OpenRouter routes >200T tokens/month across 500+ models from 80+ providers; folding the gateway into Stripe's billing/payments stack directly couples model usage with cards, stablecoins, and agentic commerce rails that Stripe has been building toward all year.
- **Go 1.27 released** — Go 1.27 is [out (Aug 19)](https://go.dev/blog/go1.27) with **generic methods on types** (so `*Rand.N[Int intType]` replaces the per-type `Int32N/Int64N/IntN` zoo), generalized function-type inference in composite literals/conversions/channel sends, struct-literal keys allowed for embedded fields, new `encoding/json/v2`, `crypto/mldsa` (post-quantum signatures), `crypto/tls` ML-DSA support, `simd/archsimd`, `testing/synctest`, and `goroutineleak` profiling. Biggest change is finally usable generic methods + stdlib SIMD, both material for high-throughput services.
- **OpenAI cyber-pacing policy** — OpenAI published ["Pacing model development in an era of cyber-critical capabilities"](https://openai.com/index/pacing-model-development-cyber-critical-capabilities/) (HN #29, 154 pts). They explicitly commit to **degrading cyber-offensive capability** in deployed frontier models via post-training if risks outpace defenses, and define "cyber-critical capabilities" thresholds tied to real CTF benchmarks — first public policy of its kind tying capability release pacing to offensive-cyber eval results rather than general "dangerous capability."
- **Go 1.27 is the headline backend item; Android AOSP Git tags vanish** — Google [stopped pushing Git tags for portions of Android source](https://news.ycombinator.com/item?id=42500000) per GrapheneOS (HN #7, 617 pts). Removing tags breaks reproducible checks of AOSP and is a quiet but significant change for Android ROM builders, security researchers, and CI pipelines that pin to specific tags.
- **Cloudflare: remote Spectre on Workers, again** — Cloudflare's ["A revisit of remote Spectre attacks on Cloudflare Workers"](https://blog.cloudflare.com/) (Aug 19) reopens the question of whether V8/WASM worklets leak across tenant boundaries via new gadgets and remote timers, plus what hardening they've shipped. Worth reading for anyone running multi-tenant JS/WASM on edge runtimes.
