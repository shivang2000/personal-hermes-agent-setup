**Tech / AI / Crypto / Software Digest — 25 September 2026, 12:55 IST**

**Top picks**
- [AlloyDB previews an architecture for bursty agent workloads](https://cloud.google.com/blog/products/databases/alloydbs-agentic-database-architecture/) — Ephemeral microVM-based PostgreSQL nodes read near-real-time data from storage segments isolated from production, expose SQL/vector/full-text search through MCP, and scale from zero to thousands of readers. The design targets autonomous agents without letting unpredictable retrieval traffic destabilize OLTP.
- [GitHub open-sources an autonomous fuzzing pipeline](https://github.blog/security/application-security/ai-powered-fuzzing-with-the-github-security-lab-taskflow-agent/) — The Taskflow Agent selects C/C++ entry points, writes AFL++ harnesses, measures source coverage, iterates on seeds and dictionaries, triages crashes, and produces vulnerability reports. Decisions stay with the LLM while MCP tools execute constrained primitives—but GitHub warns that generated build commands require a disposable VM or Codespace.
- [Google releases an agentic EKS-to-GKE migration plugin](https://cloud.google.com/blog/products/containers-kubernetes/gke-agentic-migration/) — The open-source plugin translates Terraform and Kubernetes manifests, maps IRSA/ALB/Karpenter concepts to GKE equivalents, runs deterministic validation, and emits GitOps pull requests instead of mutating clusters. Persistent state, role-separated workspaces, and mandatory approvals address long-running enterprise migrations.
- [Amazon EventBridge gets centralized, ordered enterprise buses](https://aws.amazon.com/blogs/aws/introducing-enhanced-custom-event-buses-in-amazon-eventbridge-for-enterprise-scale-event-driven-applications/) — One enhanced bus can now span AWS Organizations accounts via RAM, with per-`EventGroupId` ordering, replayable Subscriber resources, Avro/Protobuf inspection, JSONata transforms, and five-minute content-based deduplication. This can replace webs of cross-account buses and, for ordered Lambda processing, some SQS glue.
- [Bitget confirms a roughly $351.6M exchange breach](https://www.coindesk.com/markets/2026/09/25/bitget-s-usd351-million-hack-happened-via-spoofed-transfers-not-private-keys-ceo-gray-chen-says) — Withdrawals were paused while Bitget investigated what its CEO described as spoofed transfers rather than stolen private keys. Attribution to North Korea remains unconfirmed; custody teams should monitor the postmortem for transaction-validation and signer-control failures.
- [Meta details confidential cloud processing for AI glasses](https://engineering.fb.com/2026/09/23/security/private-processing-meta-ai-glasses/) — Requests traverse third-party OHTTP relays into remotely attested CPU/GPU TEEs; approved binaries are checked against a witnessed transparency ledger, while persistent memories are encrypted using user-provided keys. Anonymous credentials and non-user-specific routing are intended to prevent operators from targeting an individual session.

**AI, Agents & Models**
- [Liquid AI releases a speculative-decoding drafter for LFM2.5-VL-3B](https://huggingface.co/blog/LiquidAI/lfm2-5-vl-dspark) — The 279.5M-parameter DSpark sidecar drafts token blocks from tapped hidden states, with the target model verifying every token so outputs remain exact. Liquid reports up to 3.13× decode and 2.62× end-to-end speedups on-device, with integrations for llama.cpp, MLX-VLM, and SGLang; vision encoding and prefill remain the Amdahl’s-law bottleneck.
- [Google prepares the first orbital TPU test for Project Suncatcher](https://blog.google/innovation-and-ai/models-and-research/google-research/google-project-suncatcher-facts/) — A prototype on SpaceX’s Transporter-18 mission will test Trillium TPUs against launch vibration, radiation, and thermal-vacuum constraints. Google says proton-beam testing exceeded the expected five-year radiation dose; a 2027 two-satellite test will tackle precision laser links for clustered compute.
- [Vercel Sandbox adds persistent Drives in public beta](https://vercel.com/changelog/drives-for-vercel-sandbox-are-now-in-public-beta) — Drives survive sandbox termination and can carry agent workspaces, local memory, models, datasets, or dependency trees across runs. One sandbox receives read-write access at a time, while point-in-time snapshots can be mounted read-only by multiple workers.

**Software Engineering & DevTools**
- [How GitHub renders million-line pull requests](https://github.blog/engineering/user-experience/rendering-huge-pull-requests-in-the-github-copilot-app/) — GitHub tested against a PR containing 2,200 files, one million changed lines, and 400+ inline comments. Its renderer separates deterministic code-row geometry from lazily measured comment blocks, keeps only about 100 rows mounted, and gates measurement off the scroll hot path to avoid reflow loops.
- [F-Droid 2.0 begins rolling out](https://f-droid.org/2026/09/24/f-droid-2.0-a-new-chapter-for-android-freedom.html) — The largest client update in a decade rewrites major components in Kotlin and Jetpack Compose, adds description/category/translation search plus CJK support, and adopts Android’s pre-approval API for smoother installs. Background updates no longer require the privileged extension, although panic-triggered app wiping has not yet returned.

**Cloud, Infra, Data & Security**
- [SourceHut build-log XSS enabled account takeover](https://blog.arusekk.pl/posts/srht-account-takeover/) — CVE-2026-92973 abused unsanitized OSC 8 hyperlinks emitted by `ansi2html.py`; attacker-controlled CI output could execute when another user viewed the log, exposing CSRF tokens and potentially deploy keys. SourceHut added output sanitization, but self-hosters should update and review CSPs and any other ANSI-to-HTML renderers.

**Crypto & Blockchain Engineering**
- [SEC exemption opens a path for onchain trading of actual equity tokens](https://solana.com/news/stocks-sec-innovation-exemption) — Under the framework described by the Solana Policy Institute, eligible tokens must carry the same voting, dividend, and liquidation rights as the underlying listed share; mere price-tracking wrappers do not qualify. Builders also need token-level access controls and public disclosure of contract pause, upgrade, and override powers.
