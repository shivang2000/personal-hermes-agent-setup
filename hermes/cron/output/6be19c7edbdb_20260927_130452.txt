- [Twitch message-to-RCE chain demonstrates the danger of unsandboxed embedded browsers](https://blog.scrt.ch/2026/09/22/how-one-twitch-chat-message-became-code-execution-on-a-streamers-pc/) — An unsanitized OBS chat overlay provided JavaScript execution, then an old V8 flaw reached native code because OBS Browser Source disabled Chromium’s sandbox.
