**Top picks**

- [Shopify replaced Redis with MySQL for inventory reservations — and it scaled — Shopify Engineering](https://shopify.engineering/scaling-inventory-reservations) — 14% of US ecommerce, peak $5.1M/min on Black Friday 2025. Shopify rebuilt oversell protection on MySQL using `SELECT ... FOR UPDATE SKIP LOCKED`, one row per sellable unit (capped at 1,000 per item/location), composite primary keys to drop lock counts from 2→1 per reservation, and `READ COMMITTED` isolation to avoid gap locks. The hard lesson wasn't schema — it was connection hold-time: per-caller attribution at ProxySQL showed checkout-path code outside reservations was hogging the pool, and fixing that removed the throughput ceiling. The cleanest production write-up of "Redis → relational when you actually need ACID across two systems" in a year.
