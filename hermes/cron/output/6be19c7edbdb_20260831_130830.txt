**AI, Agents & Models**
- [How to build a diffusion language model](https://kuleshov-group.github.io/blog/blog/2026/how-to-build-a-diffusion-language-model/) — Cornell’s implementation-oriented guide covers masked and block diffusion, encoder–denoiser splits, remasking for error correction, sampling distillation, and post-training. The key tradeoff is parallel, bidirectional refinement versus the extra denoising passes and fixed-length limitations of basic MDLMs.
- [Google pushes lower-cost enterprise agent pricing](https://www.cnbc.com/video/2026/08/31/google-takes-aim-at-anthropic-microsoft-with-budget-friendly-ai-pricing.html) — Google is positioning its agent offering against Anthropic and Microsoft on price as enterprise usage scales. Builders should watch whether the discount applies to model inference, orchestration seats, or bundled cloud consumption before comparing effective task cost.
- [Underfoot records silent on-device model drift](https://umer9538.github.io/underfoot/) — The open test harness freezes prompts and captures outputs by OS/framework build. Early Apple results expose deterministic markdown-wrapped “JSON,” an availability API that reports ready while every simulator generation fails, and guardrail behavior changing independently of the model—useful evidence for version-specific mobile AI regression suites.

**Software Engineering & DevTools**
- [croc v11.3 adds direct peer-to-peer transfers](https://getcroc.com/blog/croc-v11-3-release-update) — Authenticated CLI peers now attempt PAKE-bound WireGuard via UDP hole punching, fall back to Tailscale’s encrypted DERP network, then to existing croc relays. The transport changes automatically while croc’s AES-GCM file encryption and three-word-code workflow remain intact.
- [Engineering “0 ms” perceived autocomplete over 240M domains](https://ruurtjan.com/articles/p99-0ms-autocomplete-for-240-million-domain-names) — Wirewiki prefetches the current prefix plus all possible next characters on `keydown`, hiding network latency before `keyup`. A memory trie handles the ranked head, while 240M delta-compressed names occupy about 2.5GB in an mmap’d SSD block index.
- [Haiku R1/beta6 released](https://www.haiku-os.org/news/2026-08-26_haiku_r1_beta6) — The BeOS-inspired desktop OS published its first beta in roughly two years, with supported in-place upgrades.
