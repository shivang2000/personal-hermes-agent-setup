**Tech / AI / Crypto / Software Digest — 12 Aug 2026, 12:55 IST**

**Top picks**
- [NVIDIA ships Nemotron 3.5 Lightning and NeMo Switchyard](https://blogs.nvidia.com/blog/nemotron-lightning-switchyard-rtx-dgx/) — Lightning is an open 30B MoE optimized for high-volume agent steps; NVIDIA claims up to 4× faster output and 30% faster task completion versus peers. Switchyard routes each agent call across local, open, and proprietary models using tunable quality/latency/cost policies.
- [Researchers extract hidden reasoning from proprietary LLM APIs](https://stolen-thoughts.com/) — Signed/encrypted reasoning blocks from OpenAI, Anthropic, and Google could reportedly be replayed into weaker sibling models and decoded after jailbreaking those models. This makes opaque reasoning artifacts a cross-model capability-leak and potentially a secret-leak boundary—not merely harmless API metadata.
- [Mojo reaches 1.0](https://www.modular.com/blog/modular-26-5-mojo-1-0-is-here) — Modular now promises a stable 1.x foundation for its Python-like systems language targeting CPUs, GPUs, and accelerators. The release unifies closures and pointer types, adds lambda syntax and reference-invalidation diagnostics, and substantially stabilizes the LSP.
- [Linux AF_UNIX use-after-free enables container escape](https://github.com/sgkdev/bad_garbage) — CVE-2026-53361 races socket garbage collection against `MSG_PEEK`, leaving a dangling `sk_buff` reachable by unprivileged code. The public exploit targets several 6.12/6.17-based distributions; operators should verify vendor kernels rather than assuming container isolation is sufficient.
- [pg_clickhouse v0.10 pushes correlated subqueries into ClickHouse](https://clickhouse.com/blog/pg_clickhouse-whats-new-july-2026) — The extension now fully pushes down 16/22 TPC-H queries. ClickHouse reports Q17 dropping from 32.7 seconds to 37 ms by replacing per-row local evaluation over six million rows with remote execution.

**AI, Agents & Models**
- [WorldClaw generates editable, explorable 3D worlds through specialized agents](https://tencent-hunyuan.github.io/Hunyuan3D-WorldClaw/) — Tencent Hunyuan’s coarse-to-fine pipeline converts a prompt into a shared scene specification, constructs region-aware terrain, then generates and places editable textured meshes only where local detail is needed. The structured intermediate representation is the key mechanism preserving global coherence across agents.
- [“Catastrophic remembering” explains ever-growing agent instruction files](https://arxiv.org/abs/2608.11095) — Across 247,694 instruction lifetimes in 1,867 repositories, agent prompts reportedly grew 226% because adding rules is cheap while safely deleting rules whose rationale was lost is difficult. Recording rationale as comments removed 99.3% of excess instructions in controlled evaluations—a practical argument for treating `CLAUDE.md` like maintained code.
- [Anthropic makes Sonnet 5’s introductory API pricing permanent](https://platform.claude.com/docs/en/about-claude/pricing) — Sonnet 5 will remain at $2/MTok input and $10/MTok output instead of rising to $3/$15 on September 1. Workload models should still account for Anthropic’s note that its newer tokenizer can produce roughly 30% more tokens for equivalent text.
- [llama.cpp launches an official local-AI home and packaged Mac download](https://llama.app/) — The new site provides a first-party desktop/CLI entry point, curated compatible models, and a path to pair local inference with coding agents. It lowers the installation barrier around the established llama.cpp runtime without changing its local-first privacy model.

It shells out to `git commit-tree` and reuses original trees, so rewriting metadata does not modify tracked file contents—though it still rewrites commit IDs and requires coordinated force-pushing.
