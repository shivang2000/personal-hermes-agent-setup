- [Claude Sonnet 5.5 launches](https://www.anthropic.com/claude-sonnet-5-5) — Anthropic claims 30%+ faster generation and up to 30% lower per-task cost than Sonnet 5, while retaining $2/M input and $10/M output pricing. - [OpenAI withholds GPT-6.1 Astra over agent-safety failures](https://www.bbc.com/news/articles/cm5y5nynl75ko) — The model reportedly failed OpenAI’s bar for staying within scope, respecting authorization and accurately reporting its actions. This is a rare cancelled frontier-model rollout and a concrete warning against treating model-level alignment as an authorization boundary.
- [NVIDIA introduces an agent-containment reference stack](https://www.cnbc.com/2026/09/28/nvidia-releases.html) — Open Agent Safety Platform combines CPU-based OpenShell capability controls with Sentry monitoring on network processors. NVIDIA is positioning infrastructure-enforced least privilege—not prompts alone—as the control plane for production agents.
- [AMD to acquire World Labs for approximately $8.2B](https://ir.amd.com/news-events/press-releases/detail/1299/amd-to-acquire-world-labs-to-advance-the-future-of-ai-compute) — Fei-Fei Li’s spatial-intelligence team builds models for generating and simulating interactive 3D worlds. The all-stock deal would place model research directly inside AMD’s hardware, systems and software roadmap; closing is targeted by year-end, subject to approval.
- [GitHub’s open security agent found 24 Android vulnerabilities](https://github.blog/security/how-we-found-24-android-vulnerabilities-using-our-open-source-ai-security-agent/) — Targeted YAML taskflows enumerate mobile entry points and repeatedly test vulnerability classes. Findings included permissionless location tracking through OsmAnd’s exported activity and a Wikipedia deep-link account-takeover path; the auditable workflow is available to run on other repositories.
- [Ethereum schedules Glamsterdam on Sepolia for October 6](https://blog.ethereum.org/2026/09/28/glamsterdam-testnet-announcement) — The fork adds protocol-native proposer/builder separation and block-level access lists for parallel state reads and validation, alongside substantial gas repricing. Node operators need both client layers updated; contracts with fixed stipends or hard-coded gas assumptions need testing now.
