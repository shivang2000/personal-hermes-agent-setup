- [**Demis Hassabis steps down as DeepMind CEO; Koray Kavukcuoglu elevated; Jeff Dean & Sanjay Ghemawat leave to start a public-benefit ML research corp** — `blog.google`](https://blog.google/company-news/inside-google/message-ceo/next-chapter-ai-momentum/) — Sundar's internal note (mirrored on the official blog) makes Hassabis Chair of Google DeepMind and Chief Scientist of Alphabet; Kavukcuoglu (13 years at GDM, ex-WaveNet/DQN lead) takes the operational SVP role overseeing Gemini model dev, frontier research, and the Gemini app. Jeff Dean and Sanjay Ghemawat exit after 27 years to launch an independent public-benefit corporation for ML/AI/systems research, with Google as founding investor and Cloud partner. Worth flagging for anyone whose roadmap depends on Gemini or on the trajectory of Google's open-weights Gemma (900M+ downloads cited).
- [**Cloudflare open-sources "Cloudflare OS" — an open agent + apps + work platform, with Gatekeepers, Durable Object Facets, and Cap'n Web RPC** — `blog.cloudflare.com`](https://blog.cloudflare.com/cloudflare-os/) — 357-pt HN launch. Workspace-scoped AI agent with isolated V8-isolate runtime, no internet by default; access to internal services is mediated by service-specific "Gatekeeper" Workers that hold credentials and expose a typed capability surface (e.g. `env.PROJECT.listIssues`). Each generated "app" is a Dynamic Worker + Durable Object Facet (its own SQLite), and the platform tracks every resource an agent has *observed*, so downstream sharing/apps honor the original ACL. Any model via AI Gateway, all inference spend attributed. This is the most concrete "agent OS" architecture from a major infra vendor; the open-source model (core repo + example deployment) is a direct shot at vendor-locked agent stacks.
- [**Atlassian Rovo exfiltrates Jira/Confluence data via indirect prompt injection — even with web search disabled** — `promptarmor.com`](https://www.promptarmor.com/resources/atlassian-rovo-exfiltrates-data) — PromptArmor discloses that Rovo's URL-retrieval tool (and Markdown image rendering) can be coerced into leaking tenant data after a user uploads a poisoned file. Disclosed May 23; Atlassian assigned a case but went silent for ~10 weeks, so it was published yesterday. Same family of flaws PromptArmor already documented in Slack AI, Superhuman AI, Microsoft Copilot, and Writer.com. Practical action: any org running Rovo against sensitive Jira/Confluence content should treat user-uploaded files as untrusted, watch Atlassian's advisory closely, and apply DLP on outbound exfil channels.
- [**Neon ships a 4B open-source retrieval model it claims matches GPT-5.6 Sol at ~100× lower cost** — `neon.com`](https://neon.com/blog) — Databricks-owned Neon published (Aug 5) a recipe for fine-tuning a small open retrieval model on their own Postgres-resident data and beating OpenAI's flagship retrieval on their internal evaluation; the post headline is "How Castform + Neon Beats Frontier Models on Price and Efficiency." Pair with the new per-project permissions feature (Aug 3) and the Lakebase text/vector/hybrid search stack — the broader play is "your agent's training data already lives in your Postgres; use it."
- [**Deno ships "Celld" — self-hosted, distributed Durable Objects** — `github.com/denoland/celld`](https://github.com/denoland/celld) — Apache-2.0 Rust server that brings Cloudflare-style per-key single-writer consistency (each "cell" = a bucket of keys, durable replication, watermark-based shedding, no global rebalance needed) to your own infra. 497 stars in <24h. Interesting for anyone who liked the Durable Object model but didn't want to be locked to CF Workers — the README is unusually explicit about the tradeoffs (memory/CPU triggers, ownership fencing, spare-node behavior).
