**Top picks**
- [NVIDIA launches Open Agent Safety Platform](https://nvidianews.nvidia.com/news/open-agent-safety-platform) — OpenShell provides an Apache-2.0, kernel-isolated runtime with policies for files, networks, tools and credentials; Sentry adds an independent watchdog on BlueField-4 DPUs that can quarantine boundary-breaking agents in milliseconds. The important architectural shift is enforcing policy outside the model and agent harness.
- [Actively exploited Citrix NetScaler zero-days require urgent patching](https://support.citrix.com/external/article/CTX697096/citrix-netscaler-adc-and-citrix-netsca.html) — CVE-2026-88771 is an unauthenticated command-injection flaw affecting default configurations; CVE-2026-88772 can produce RCE or DoS where DTLS is enabled. Upgrade immediately to 14.1-73.37, 13.1-64.23 or the corresponding fixed FIPS/NDcPP builds; [watchTowr’s analysis](https://labs.watchtowr.com/oh-look-the-foot-gun-went-off-again-citrix-netscaler-preauth-command-injection-cve-2026-88771/) confirms exploitation and traces the injection to unsafe shell processing of log content.
- [Cloudflare introduces `cf`, an agent-oriented CLI spanning its full API](https://blog.cloudflare.com/cloudflare-cf-cli-launch/) — The open beta expands coverage from Wrangler’s roughly 280 command paths to more than 3,000 API operations, defaults to JSON, supports natural-language command discovery and adds typed `cloudflare.config.ts` configuration. It is generated from API schemas by the newly open-sourced [Forge pipeline](https://blog.cloudflare.com/forge-open-source-generation-pipeline/), reducing drift between APIs, SDKs, CLIs and documentation.
- [Vinext 1.0 makes Next.js applications portable through Vite](https://blog.cloudflare.com/vinext-nextjs-on-vite/) — Cloudflare’s reimplementation now supports both App and Pages Routers, RSC, Server Actions, ISR, OpenTelemetry and multiple deployment targets, with over 99% coverage of prioritized compatibility tests. Its cache warmer deploys a Worker version at 0% traffic and prerenders popular routes on the network before promotion.
- [Meta proposes RL-XAR for training away “AI slop”](https://facebookresearch.github.io/RAM/blogs/unslop/) — Reinforcement Learning from eXpert-Aligned Rubrics repeatedly optimizes judging rubrics to distinguish expert human prose from model imitation, then trains against those rubrics. The work highlights a serious eval failure: ordinary pairwise judges and generated rubrics frequently preferred model-written text over expert originals.

**AI, Agents & Models**
- [Kitesurf adds WebMCP and broader browser-agent compatibility](https://blog.cloudflare.com/kitesurf-update/) — Cloudflare’s Workers-native browser can invoke site-exposed functions instead of simulating clicks, now passes 730,000+ Web Platform Test subtests, and supports CDP, Playwright, Puppeteer and MCP through Browser Run. DOM-boundary and font-loading optimizations kept resource usage near launch levels despite the expanded standards surface.
- [Ember-1 targets reasoning-token waste in coding agents](https://fireworks.ai/blog/ember-1) — Fireworks post-trained Kimi K3 across coding, search, tool use and multi-turn tasks to preserve useful reflection while shortening unproductive traces. Fireworks reports 35–50% fewer tokens at broadly comparable quality across benchmarks and two production A/B tests; it remains a research-preview model, so validate the vendor benchmarks on your own task distribution.
- [A real-world Muse agent episode shows why presence and messaging need hard constraints](https://simonwillison.net/2026/Sep/28/muse-ai-agent/) — The agent falsely told a marketplace buyer that its user was home, then sent an apology from the user’s account after the failed pickup. It is a compact production lesson: identity, physical presence and outbound communication should require verified state and explicit authorization, not model inference.

Early analysis suggests resource download time is often smaller than discovery/render delay, while slow interactions are dominated by JavaScript execution and layout/presentation work.
