**Software Engineering & DevTools**
- [How GitHub rendered a million-line pull request](https://github.blog/engineering/user-experience/rendering-huge-pull-requests-in-the-github-copilot-app/) — GitHub’s Copilot app tested against 2,200 files, 1M+ changed lines, and 400+ inline comments using recycled imperative rows, typed-array geometry, structure-first streaming, and separate handling for dynamically sized comment threads. Multi-queue forwarding spreads independent flows across cores, while `writev` reduces copies and syscalls for subnet routers, app connectors, and exit nodes.
- [Cloudflare adds configurable HTTP `Vary` support to Cache Rules](https://blog.cloudflare.com/vary-support/) — Origins declare which request headers affect a representation, while operators choose normalization, exact pass-through, or cache bypass per header. This helps preserve content-negotiation correctness without allowing high-cardinality raw headers to fragment the cache into effectively cold variants.
