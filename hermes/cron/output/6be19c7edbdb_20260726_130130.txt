Cloudflare argues that operationally unreliable ORIGIN should be removed from route selection.

**AI, Agents & Models**
- [Inflect-Micro-v2: end-to-end TTS in 9.36M parameters](https://huggingface.co/owensong/Inflect-Micro-v2) — The Apache-2.0 fixed-voice English model produces 24 kHz waveforms directly, occupies 37.5 MB in FP32, and supports deterministic CPU or CUDA inference. It is an unusually small option for offline voice interfaces and edge agents.
- [A 28.9M-parameter language model runs on an ESP32-S3](https://github.com/slvDev/esp32-ai) — The project implements TinyStories-scale inference on an inexpensive microcontroller rather than merely using the device as an API client. It is valuable as a concrete reference for extreme memory budgeting, quantization, and embedded autoregressive inference.

**Cloud, Infra, Data & Security**
