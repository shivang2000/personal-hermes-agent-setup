**Top picks**
- [OpenAI responds after SpaceX acquires Cursor](https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/) — The acquisition puts a leading coding environment inside SpaceX and prompted an immediate public response from OpenAI. Watch for changes to Cursor’s model access, vendor neutrality, enterprise terms, and product roadmap.
- [GLM-5.3 released as an open-weights coding and cyber model](https://huggingface.co/zai-org/GLM-5.3) — Z.ai says the base model is unchanged from 5.2 and the gains come entirely from post-training. Maker-reported results rise from 4.6 to 28.3 on Terminal-Bench 3.0 and 24.4 to 54.4 on ExploitBench; local serving recipes cover SGLang, vLLM, Transformers, KTransformers, and Unsloth.
- [Critical Cosmos EVM balance bug exploited across six chains](https://thehackernews.com/2026/08/cosmos-evm-flaw-exploited-after-cosmos.html) — An unchecked subtraction involving vesting accounts could wrap a spendable balance toward `2^256`, after which SDK/EVM reconciliation could mint, burn, or corrupt balances. Cosmos EVM operators need v0.6.2 or v0.7.2+, delivered through a coordinated state-breaking upgrade; the reported attacks moved millions of dollars in assets.
- [htmx 4.0 moves its transport core from XHR to `fetch()`](https://four.htmx.org/announcements/2026-08-28-htmx-4.0.0-is-released) — The major migration changes attribute inheritance to explicit opt-in, standardizes event names, replaces default `localStorage` history snapshots with re-fetching, and adds built-in morph swaps plus `<hx-partial>`. Version 4 remains under npm’s `next` tag until early 2027 to avoid silently upgrading CDN users.
- [OpenAI’s Python SDK switches from HTTPX to HTTPX2](https://github.com/openai/openai-python/blob/main/httpx2.md) — Default API behavior remains compatible, but the transitive `httpx` and `certifi` dependencies disappear. HTTPX2 uses the OS trust store, so minimal containers and corporate TLS-proxy environments should install system CAs or explicitly configure `SSL_CERT_FILE`/an `SSLContext`.

**AI, Agents & Models**
- [Lemmalog treats agent memory as incremental program analysis](https://pwning.systems/posts/llm-memory-program-analysis/) — Instead of retrieving conversation fragments and asking the model to reconstruct beliefs, it converts observations into Datalog facts with derivation provenance, validity intervals, and automatic retractions. This is a useful architecture for long-running security or research agents where invalidating one assumption must also invalidate dependent conclusions.
- [OpenLake launches an open-source, S3-compatible storage engine for AI workloads](https://www.theopenlake.com/blog/introducing-openlake) — Its design combines pinned thread-per-core processing, `io_uring`, distributed metadata, RDMA, and client-side “deferred materialization” for compressed transfers into GPU memory. The vendor reports ~600µs small-object reads and up to 8× conventional object-store throughput; those claims still need independent reproduction.

**Hardware & AI Infrastructure**
- [Samsung demonstrates compute inside LPDDR5X memory](https://chipsandcheese.com/p/hot-chips-2026-samsungs-processing) — Samsung places a low-precision MAC block beside each of 16 DRAM banks, exposing an aggregate 614GB/s of internal bandwidth versus 76.8GB/s through the normal external interface. It preserves standard LPDDR commands via reserved rows, but cache coherence, speculative loads, context switching, and isolation between PIM and ordinary memory access remain substantial software problems.
